## What changed

- `save.txt` gains two kinds of line:
  - `notes <perfect total> <great total>`;
  - `costume <dNNN id> <lives>`, one line per costume worn.

  Older saves load as zero. Nothing is lost, because `save::Load` already keeps lines it does not know.
- `save::Play` carries the live's PERFECT and GREAT counts and the costume id. `save::Record` adds them; the base model (no costume) is not counted.
- The live result (`LiveResult::costume`) reports the costume actually worn. That includes the song's own pick when none was chosen (`live::PickCostume`).
- `mission::ProgressOf` handles kinds 5, 6 and 41. Kind 41's `p1` is the dress id, the same NNN as the `dNNN` folder.
- The mission log fills `[p1]` with the costume's name for kinds 40–48.

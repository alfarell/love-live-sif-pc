# M7: nameplate (accolade and badge choice)

Date: 2026-11-07 14:53 (Asia/Jakarta). Follows `202611071330-analysis.md` (Task List tabs).

## What the game has

- The top-menu header `ui2/10_top_menu` `uil0009_PlayerDataTop00` places four nodes:
  - `uip0009_PlayerDataBG00`: the background plate, in µ's, Aqours and Saint Snow forms.
  - `uip0008_PlayerData00`: text box 0 is the date and time, box 1 is the boost-item count. Both hold Japanese placeholders in the package.
  - `ctg03_uip0004_Title00`: the accolade plate.
  - `ctg03_uil0005_NameSet00`: places `uip0005_NamePlate00` and `uip0006_Badge00`.

  The `ctg03_` prefix means the part comes from `ui2/03_card`. The node names were read with `work/m7/nodes.py`, which uses `repository/tools/bmar_dump.py`.
- Each part has one textured material and one or two text boxes (probed by drawing marker strings):

  | Part | Material | Placeholder picture | Box 0 | Box 1 |
  |---|---|---|---|---|
  | Title00 | `title_plate00_M` | `title_plate_0001` | accolade name, centred | over box 0's left part; meaning not known |
  | NamePlate00 | `name_plate00_M` | `name_plate_011_0011` | player name | over box 0's left part; meaning not known |
  | Badge00 | `badge00_M` | `badge_plate_001_0` | badge name, on the ribbon | none |

- Pictures (one package each, under `ui/`):
  - `ui_honorific_title.pac/texture.pac/title_plate_%04d`: accolade row +0x08. All 368 distinct values in the 1665 rows have a picture, checked with `work/m7/plate_probe.py`. There is also a small `_s` set in `ui_honorific_title_s.pac`.
  - `ui_badge.pac/texture.pac/badge_plate_%03d_0`: badge row +0x04 (category). All 61 categories have a picture.
  - `ui_name_plate.pac/texture.pac/name_plate_%03d_%04d`: the id in `s_name_plate_datas` (12-byte rows) split as id / 10000 and id % 10000.
- The game's own editor is the Profile Card screen in `ui2/40_collection`. Its layouts include `uil0031_PlateChangeMenu00`, `uil0033_PlatePreview00` and `uip0028_ProfilePlate00`. It needs its own screen states. `--ui` shows only its corner buttons without them.

## What the port does now

- **Header:** `RunTopMenu` takes a `Nameplate` (`repository/src/app/top_menu.h`). `ApplyNameplate` sets the accolade and badge pictures and the three names. It also writes the real date and time into box 0 and empties the boost-item box.
- **Choosing:** in the top menu, Collection → Profile Card no longer leaves the menu. It edits the header in place:
  - Up/Down step through the accolades.
  - Left/Right step through the badges.
  - Enter or Esc finish.

  *Shortcut:* the game's Profile Card screen is not built.
- **Choosable items:** built by `MakeNameplate` in `main.cpp`:
  - Accolades: 2 "新入生" (newcomer), then the earned ones.
  - Badges: 901001, 902001 and 903001 (µ's, Aqours and Saint Snow "大好き"), then the earned ones.
  - "Earned" means the reward-type-4 ids of completed missions (`mission::EarnedAwards`), matched against both tables.

  *Hypothesis:* those starters are what the game gives a new player. This is not traced in the eboot, and the game's other badge unlocks are not known.
- **Save:** `save.txt` gains `accolade N` and `badge N` lines. They are written only when the player actually changes the choice, so a plain visit does not touch the save.
- **Engine fix:** `UiScreen` read text boxes (`ui_text.bin`) only from the screen's own package, so parts from another package had no text.
  - It now reads the table of every package it loads parts from.
  - Boxes from another package start empty: their default strings are placeholders the game replaces. One example is the help bar's "現在開催中のイベントを確認します。", which showed on every screen when the defaults were kept.

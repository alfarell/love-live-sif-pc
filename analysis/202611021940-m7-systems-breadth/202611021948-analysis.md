## 1. Save (`src/game/save/save.{h,cpp}`)

- **File:** `save.txt` in the data folder, plain text:
  - a header line `sif-port save 1`;
  - `player <name>`;
  - one `record <song> <variant> <best score> <best combo> <best rank> <best rate x 10000> <plays> <clears> <full combos>` per chart.
- **Unknown lines** are kept and written back. A damaged record line is kept as unknown rather than dropped.
- **Safe write:** `save.txt.tmp`, then rename over `save.txt`.
- **Reading:** a missing file is an empty save. A file without the header is refused. The boot flow then plays without saving, and never overwrites it.
- **`Record`:** counts the play, keeps the bests, and reports which of score, combo and rate are new. Every finished live counts as a clear (`shortcut:`; the game uses its life gauge, which the port does not have).
- **Test:** `tests/unit/save_test.cpp` (`sif_save_test`) covers:
  - the missing file;
  - the update rule across two plays;
  - a round trip (name with spaces, record, unknown line);
  - no `.tmp` left behind;
  - a foreign file refused.

## 2. Screens

- **Boot flow (`main.cpp`):** loads the save at start. After each live played to its end, it records the play and writes the save, then passes the new bests to the result.
- **Result:** the `common_uip0017_New_00…02` instances in `uil0005_PlayScoreWin00` show "NEW" by the score, max combo and clear rate rows. The row order is a *Hypothesis*; it matches the rows on screen.
- **Song select** (atlases from `ui2/20_setup`):
  - `setup_result_evaluation00`: D C B A S SS SSS in cells of 0.125, the same order as `Judge::Rank()`;
  - `setup_result_combo00`: rows "MAXCOMBO:", FULL COMBO, ALL PERFECT;
  - `setup_select_playstatus_text00_00/01/02`: "Unplayed" and two unlock hints ("Unlock by getting A or higher in HYPER / EXTREME(AC)").

  Using them:
  - song-step cards show the best rank (`lank_result00`) for played charts;
  - difficulty-step plates show the best rank (`clearrank00`) instead of "Unplayed", plus FULL COMBO (`combostatus00`) once achieved;
  - unlock hints and locks stay hidden (nothing is locked in the port).

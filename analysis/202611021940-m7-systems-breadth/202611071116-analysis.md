# M7 step: story/talk (member voice lines on the top menu)

## 1. What "story/talk" is in this game

- `talk/talk.pac` holds voiced member lines for the home screens, not story text. Format notes: `repository/docs/formats/talk.md`.
- **Not found:** a story mode with text scenes. `message.pac` (816 messages) holds UI text only. No talk file names a message.

## 2. Findings

1. **When a talk plays:** `talk_data.bin` (BLBN table `ll3::talk::s_talk_datas`) has one 16-byte row per talk: id, condition type, parameter, weight.
   - Type 1 rows are hour ranges, packed `end << 16 | start`. They give the greetings: 50 morning (5-13 h), 51 afternoon (13-19 h), 52 evening (19-21 h), 53 night (21-23 h), 6 late night (23-5 h).
   - Type 0 rows (talks 0-10, except 6) can play at any time.
   - Types 2-28 are not decoded. *Hypothesis:* dates (type 2 talk 54 has `000a000c` = 12/10?), play counts, and unlocks.
2. **What a talk says:** each `talk_NNNN.btlb` is a `BTL` timeline. Its voice event (tag 0x0514, kind 8) gives the cue number. The cue name pattern (`vo_ac_001_505`, or `vo_ac_21_001` for Saint Snow) resolves 1374 of 1380 voice events in `voice.acb`.
3. **The rest of the timeline** (tags 0x0028 / 0x0443, kind 4) is not decoded. *Hypothesis:* motions and expressions of the 3D navigator, which is not built.

## 3. Port

- `src/game/talk/talk.{h,cpp}`:
  - `TalkIds(vfs, member)`;
  - `VoiceCue(vfs, member, id)`, which scans for the voice event (shortcut: the BTL timeline is not decoded);
  - `LoadRules(vfs)` and `GreetingFor(rules, hour)`.
- **Top menu** (`RunTopMenu(..., &audio)`):
  - the navigator greets by the local hour on entry;
  - **T** (pad Triangle) says a random any-time line.
  - Shortcut: the navigator is always Honoka (member 1).
- `tests/unit/talk_test.cpp` (`sif_talk_test <dump>`) checks:
  - 92 talks for Honoka;
  - talk 0 → `vo_ac_001_505`;
  - Saint Snow two-digit cues;
  - the 92 rules and the five greetings by hour;
  - that `vo_ac_001_505` decodes (1.36 s).
- **Verified:** all 10 tests pass, and Debug and Release are rebuilt. A run of `--menu` logged `talk 50: vo_ac_001_503` (morning greeting), and two T presses gave `vo_ac_001_506` and `vo_ac_001_501`.

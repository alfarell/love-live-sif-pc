# M7 step: top-menu entry fix and the Task List screen

## 1. Top-menu entries were shifted by one mode (fixed)

- **What was wrong:** with Event focused, the submenu showed Profile Card / Member Card / Skill Card, and with Collection focused it showed the Options items (captures `work/m7/menu_event.png`, `menu_collection.png`).
- **Labels by id:** the label atlas `ui2/10_top_menu_en.pac/uip0006_SubMenuList01.pac/texture.pac/top_mode_sub00_on_T` (4 labels per row, id = row × 4 + column) gives:

| Ids | Labels |
|---|---|
| 0-3 | Play Live Show, Play Live Show (AC), View Live Show, Live Show Medley |
| 4, 6, 11 | blank |
| 5 | Create/Change Costumes |
| 7 | List of Costume Materials |
| 8, 9 | Songs, Costumes |
| 10 | Game Settings |
| 12-14 | Control Settings, Sound, Credits |
| 15-19 | Profile Card, Member Card, Skill Card, Photo Gallery, School Idol Festival AC Archive |
| 20-22 | Task List, Ongoing Events, Rankings |

- **Cause:** the M6 reading of the pointer table at 0xC085A0 gave each mode the previous mode's ids.
- **Correct table** (it also matches each mode's submenu size: 4, 2, 2, 4, 5, 3):

| Mode | Entry ids |
|---|---|
| Play | {0, 1, 2, 3} |
| Costumes | {5, 7} |
| Additional Purchase | {8, 9} |
| Options | {10, 12, 13, 14} |
| Collection | {15-19} |
| Event | {20, 21, 22} |

- **Correction to an earlier note:** `202611031153-analysis.md` said Options entry 8 is Sound Settings. Id 8 is "Songs" (Additional Purchase). Sound is 13. The port opened the Sound page from a "Songs" label until now.
- **Fixed:** `src/app/top_menu.cpp` `kEntriesOfMode` and the routing in `main.cpp` (Options 13 → Sound, 10 → Game Settings).
- **Checked:** captures `menu_options_fixed.png` (Game Settings, Control Settings, Sound, Credits) and `menu_event_fixed.png` (Task List, Ongoing Events, Rankings).

## 2. Task List screen (`ui2/50_event`)

- **Layouts:**
  - `uil0001_MisLayout00` is the screen (background, character, group tabs, frame, scroll bar, plate list, title, ticker).
  - `uil0002_MisframeLayout00` has the 4 tab layouts: member, common, music, costume.
  - `uil0003_MisplateLayout00` places 7 plates. Plate `_00` sits above the frame and `_06` below it.
- **Plate** (`uil0004_missionplateAll00` → `uip0001_mission_plate00`):
  - text boxes, found by filling probe labels: 0 title, 2 description, 3 progress "n/m", 4 reward count, 5 "press ◉ to claim"; 1, 6 and 7 are unused here;
  - gauge `M_misgauge00` (texture filled from u 162 to 862 of 1024);
  - `status_icon00` COMPLETED, `status_icon01` GET!;
  - `mission_plate00_ON` / `_OFF` / `_ef` for the focus;
  - reward icon nodes.
- **Port (`src/app/mission_screen.{h,cpp}`):**
  - Top menu → Event → Task List opens it.
  - It lists the missions the port can track (1419 with all add-ons), titles and descriptions in the UI language, songs not owned left out.
  - Each plate shows progress and the gauge, and COMPLETED when done.
  - Up/Down move the focus, Left/Right move a page, Esc goes back.
- **Checked:** captures `work/m7/tasks.png` (first page: mission 0 done, 1/10, 1/50, …) and `tasks_scrolled.png` (after 14 steps).

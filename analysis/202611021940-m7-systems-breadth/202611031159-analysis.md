# M7 step 3: the costume step

Created: 202611031159 (Asia/Jakarta). Follows `202611031153-analysis.md`.

## 1. What the game has

- **Song select's costume step** (`uil0025_CosSelect00`):
  - plates `uip0045_CosSelect00` (one in each song-list plate) with a 150 × 150 costume icon (`cos_icon00_M`), two member-card pictures (`card_center00_M`, `card_R00_M`: `mbc_1xxxx`) and a name box;
  - `uip0047_CharaCard00`;
  - a curtain (`uip0059_CosCurtain00`);
  - `ctg30_` parts from `ui2/30_costume`: name, info, preview, fitting mark.
- **Member cards:** `ui/ui_member_card_thumbnail[_lang].pac` has about 1,056 `mbc_` textures, in pairs per card. So the game dresses **each member** through the card in their slot, which ties the step to the card collection (an M7 item of its own: cards, items, profile).
- **Costume thumbnails:** `ui/ui_dress_thumbnail.pac` `dress_thumb_NNNN`, 448 × 448, one per costume id (70). There is none for d000.

## 2. Port

- `live::CostumesFor(vfs, song, dresses)`: the costumes **every** member of the song has a model for. d000 comes first, named "School Uniform" by the port (it is not in the table), then the table's costumes in its order. `PickCostume` now uses it: the costume named like the song, else the first of the list. The rule is the same as before.
- **Song select:** a costume step after the stage step (song → difficulty → stage → costume → start; Esc goes back one step; a step with nothing to choose is skipped).
  - The song-list plates switch to `uip0045`: the costume thumbnail in the icon slot and the name in text box 0. The member-card pictures, lock and effect nodes are hidden, and focus uses `cos_select_bg00_on/off`.
  - It starts on the last choice for the same song, else on the default pick.
  - The choice goes through `SongChoice::costume` to `LiveOptions::costume`.
- **Shortcut** (in the code): one costume for everyone; per-member costumes need the member-card system.
- **Tests** (`live_test`): 0030's list starts with the uniform; 1940's list is the 3 Saint Snow costumes.

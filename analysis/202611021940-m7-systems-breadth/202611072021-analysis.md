## Layout facts

- **List window:** one group per kind, each a fixed grid of placed layouts (from the node positions):

  | Group | Slots | Grid | First row at y |
  |---|---|---|---|
  | Accolades `uil0062` | 48 | 4 × 12, rows 76 apart | 399 |
  | Name plates `uil0063` | 30 | 3 × 10, rows 92 apart | 415 |
  | Badges `uil0064` | 48 | 4 × 12, rows 76 apart | 399 |

  Frames, photos and skill cards have groups of their own. At rest the rows sit above the window, so the game scrolls the group.
- **Each slot** is a background (`uip0017_IconBack01`, used here as the focus mark), the 03_card plate part, and a star (`uip0004_StarMark00`, the current choice).
- **Labels are texture cells:**
  - tabs: `col_pro_select_text00_T`, 4 × 2 cells (Card Frame, Photo, Accolade, Name Plate / Badge, Skill Card, Player's Name);
  - page title: `col_pro_title_text00_T`, 2 rows (Edit Profile Card, Change Accolade or Name Plate).

## What the port does now

- **The screen:** `RunProfile` (`src/app/profile_screen.cpp`), opened by Collection → Profile Card.
  - PageUp/PageDown switch the three tabs; arrows move in the 4- or 3-column grid; Enter chooses; Esc leaves.
  - Pages show the rows that fit (6, 5, 6). Each row is shifted into the window with the new `UiScreen::MoveInstance`, a generic per-instance offset. *Shortcut:* the shift was measured on a capture; there is no smooth scroll.
  - The preview uses the shared `ShowNameplate`, the same drawing as the top-menu header.
- **The top menu:** its header editor is gone. `TitlePlatePath`, `NamePlatePath`, `BadgePlatePath` and `ShowNameplate` are shared (`top_menu.h`).
- *Shortcuts:*
  - The Profile Card menu screen (uil0090) is skipped.
  - Player's Name is shown but not selectable (no text entry).
  - Finish Editing is not a button.
  - The preview heading stays the package's Japanese "完成イメージ".

The M0 item "copy pt-pc platform pieces (log, crash, threads, settings, user data, os)" is done for log, crash, threads and os only. pt-pc's `settings.*` (521 lines) is a P.T.-shaped struct (Part 5 §3), and `user_data.*` (1,169 lines) is mostly migration from a legacy folder. ## 4. Build and exit-criterion results

- **Configure + build:** `vcvars64.bat` (VS 2026), then `cmake --preset debug && cmake --build ../work/build/debug`. 288 steps including SDL3 `release-3.4.16`; outputs `work/build/debug/sif.exe` (7.7 MB debug) and `sif_log_test.exe`.
- **Warnings:** the first build showed 4, all in copied pt-pc files (`getenv`/`_wfopen` deprecation; raw NUL bytes inside `'\0'` literals in `os.cpp`, see Part 9 note). Fixed by adding `_CRT_SECURE_NO_WARNINGS` to `sif_engine` and writing the two literals as `'\0'` / `L'\0'` (NUL count 2 → 0). The rebuild has **0 warnings**.
- **Exit criterion:**
  1. `sif_log_test.exe` prints `log_test ok`, exit 0.
  2. `sif.exe --frames 60 --data run` opens the 1280×720 window. `run/sif.log` shows "crash reporting: build dev", "sif-port dev starting", "window created 1280x720", "exit: code 0 (normal end)"; exit code 0.
  3. `sif.exe --crash --data run` logs "crash: unhandled exception 0xc0000005 at …, dump run\sif-crash-dev-20261031-184118.dmp" and "exit: code -1073741819 (crash)"; the dump file exists (165,879 bytes).
- **Vulkan SDK:** the user installed **1.4.363.0** (`VULKAN_SDK=C:\VulkanSDK\1.4.363.0`, machine and user). `glslc --version` → "shaderc v2026.4"; `Include\vulkan\vulkan.h` present. Ready for M3. Shells opened before the install don't see the variable; restart the terminal, or use the full path.
- **Asset check:** `py -3.14 -I repository\tools\no_assets_check.py . --all` → 74 files checked, 0 suspicious (its built-in self-check passes first).

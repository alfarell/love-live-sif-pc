## Code

### `src/app/route.{h,cpp}`: the player

**Script:** one command per line, with `#` comments:

| Command | Effect |
|---|---|
| `wait 500ms` / `wait 2s` | Pause |
| `key NAME` | Press and release: enter, esc, arrows, pageup/pagedown, t, space, the lane keys `a s d f j k l ;` |
| `press NAME until SCREEN [limit]` | Press once a second until that screen shows. Added after the first run: counting key presses through loading screens put one Enter too many into the top menu |
| `expect screen NAME [limit]` | Wait until that screen is shown (default limit 15 s) |
| `expect log TEXT` | Wait until a log line has TEXT (default limit 15 s) |
| `expect nolog TEXT` | Fail if a log line so far has TEXT |
| `shot NAME` | Save the window as a BMP |
| `timeout 120s` | The whole route's limit (default 180 s) |
| `quit` | End here (pass) |

**Errors:** a bad script is refused with its line number.

**Playing:**
- **Input:** `Inject()` runs first in `sif::PollEvent`, so scripted keys reach the screens like real ones (key down, key up 60 ms later, scancode, key code and timestamp filled). No OS input is used.
- **End of the route:** after the last command, or on a failure, the player sends `SDL_EVENT_QUIT` at most every 100 ms, so every screen closes in its own way.
- **Log:** `route: PASS (… s)` or `route: FAIL line N: <why>`.
- **Exit code:** `ExitCode()` (used by `main`'s `Quit`) makes it 0 for a pass and 3 for a fail, including when the app ends before the route does, and the exit log says "route passed" or "route failed".

**`shot`:** `PrintWindow` (client area, full content) of the port's own window into a DIB, saved with `SDL_SaveBMP` to `<shots>/NAME.bmp`. The default folder is `<data>/shots`.

## Decisions

- **Hidden or visible:** routes run hidden by default; a route whose shots are wanted runs with a visible window. The window never needs focus, because keys are injected. This goes into R2's runner (`--shots` turns hiding off).
- **The many `texture … not found` warnings:** these are UI placeholder textures known since M6. Routes check `expect nolog error`, not warnings.

`docs/PLAY.md` lists the three new options.

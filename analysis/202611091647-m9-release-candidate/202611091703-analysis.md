## `repository/tools/routes.py`

Standard library only, run with `py -3.14 -I`:

```
tools/routes.py --exe <sif.exe> --game <dump> [--only NAME ...] [--shots] [--out DIR]
```

**For each route** (`tests/routes/*.txt`, in name order):
- **Data folder:** a fresh one under `--out`, default `../work/routes/<route>` (git-ignored). Its seed `settings.ini` names the dump and sets the volume to 0, so routes are silent. The user's own data folder is never used.
- **Header directives**, comment lines the port ignores:
  - `#! seed NAME`: copy `tests/routes/seeds/NAME.txt` as `save.txt`;
  - `#! args …`: extra flags, e.g. `--lang cn`;
  - `#! data NAME`: routes sharing one data folder, for a save carried from one route to the next. The first route of the group starts it empty.
- **Running:** `sif.exe --data … --route … --shots <data>/shots/<route>`, plus `--hidden` unless `--shots` was given. A hidden window's pictures are black (R1). The process is killed if it runs past the route's own `timeout` plus 60 s.
- **Result:** PASS needs exit code 0 **and** a `route: PASS` line in `sif.log`. Otherwise the table shows the exit code and the route's own `FAIL line N: …` text.
- **Output:** one line per route (name, PASS/FAIL, time, reason) and a summary. Exit code 1 if any route failed.

**Also:**
- `tests/routes/seeds/README.md` holds the folder for save seeds, which are port-made text files, never game data.
- `docs/BUILD.md` has a "routes" paragraph under Tests.

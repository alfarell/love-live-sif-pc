## Change

**`src/game/live/chart.h`:**
- `kHomeLanes = {1, 2, 3, 5, 6, 7}`, the six home lanes L1, ←, ↓, ✕, ○, R1;
- `IsHomeVariant(variant)`, true for variants 10-13;
- `Chart::home`, set by `LoadSong` (`song.cpp`) from the variant.

**Decision: home notes keep their arcade lane numbers.** The plan said lanes 0-5, but:
- the keyboard keys of arcade lanes 1, 2, 3, 5, 6, 7 are S D F J K L, the plan's 6-lane keys;
- the arcade Button Controls slots of those lanes default to L1, ←, ↓, ✕, ○, R1, the game's 6-lane default.

So input, judgement and the key logs need no remapping. K2 only changes where those lanes are drawn (← and ○ at 140° and 40°, and no rings for lanes 0, 4 and 8).

**Note 0** stays skipped. The comment on `Chart::skipped` now gives the reason: the game does not count these events.

**Holds:** home charts use the same note lengths as the arcade ones (120 ticks for taps; 480 and longer for holds; BEGINNER even shares Normal's lengths exactly). So the reader's rule "longer than 120 ticks is a hold" applies to both.

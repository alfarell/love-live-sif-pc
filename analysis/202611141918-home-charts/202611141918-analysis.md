# Home-version charts: first survey

Date: 2026-11-14 19:18 (Asia/Jakarta). This is the start of the milestone after M9: the home-version charts ("Play Live Show", as opposed to "Play Live Show (AC)"). This file covers what the data and earlier analyses show. The game run (shadPS4) is still to come.

## The charts

**The variants** (eboot strings, M4):

| Variant | Name | Label in the game | Difficulty index (`s_live_datas` +0x14) |
|---|---|---|---|
| `_10` | `cs_basic` | BEGINNER | 5 |
| `_11` | `cs_regular` | STANDARD | 6 |
| `_12` | `cs_expert` | HYPER | 7 |
| `_13` | `cs_master` | ADVENTURE | 8 |

The labels come from the song select's label atlas (M6). Indices 5-8 select the score multipliers 1.5-3.0 (U5) and the travel times (F3).

**Every song has them.** All 130 songs in the dump have all nine charts, `_00`-`_04` and `_10`-`_13` (`work/m10/live_list.csv`, from `tools/pac_list.py`).

**Lanes.** Note numbers 55-63 are the nine arcade lanes, left to right: L2, L1, ←, ↓, →/□, ✕, ○, R1, R2 (`chart.h`). Over all 130 songs (`work/m10/lane_survey.py`):

| Variant | Note numbers used | Charts |
|---|---|---|
| `_12`, `_13` (HYPER, ADVENTURE) | 56, 57, 58, 60, 61, 62 = **L1, ←, ↓, ✕, ○, R1** | 128 of 130; 2 use only the middle four |
| `_10`, `_11` (BEGINNER, STANDARD) | 56, 58, 60, 62 = **L1, ↓, ✕, R1** | 127 of 130; 2 use only ↓ and ✕; 1 has a single 57 |
| `_00`-`_04` (arcade) | up to all of 55-63 | — |

- **No home chart uses 55, 59 or 63** (L2, the centre, R2).
- **The six home lanes are exactly the game's 6-lane Button Controls default:** L1, ←, ↓, ✕, ○, R1 (M7, `analysis/202611021940-m7-systems-breadth/202611071821-analysis.md`).
- **BEGINNER and STANDARD use four of those six.** They use the same 6-ring form: the game's Control Settings shows the same 6-lane picture for "BEGINNER, STANDARD" and "HYPER, ADVENTURE" (`work/m7/kc_other.png`, both forms).
- **"3-lane" was wrong.** The earlier wording ("3- and 6-lane", PLAY.md and M7) was a guess. The UI layout `uil0012_keySetting00` has only two lane groups, `button_9` and `button_6`.

**Note number 0.**
- It appears **only in home charts**: 16, 133, 517 and 2426 events in `_10` to `_13` across all songs. Song 0340 `_13` has 6, at ticks 5520 to 137760, with lengths of 120 to 1680 ticks.
- The chart reader counts them as `skipped` (M4).
- Their number grows with difficulty. So they are probably a home-only kind of note or event, not noise. *Hypothesis:* a special note (for example one that needs several buttons) or a cue for an effect. The game run should show it.

**Other channels.** Channels 2-4 (extra notes) and 5 (phases, finale) have the same shape as in the arcade charts. Channels 6 and 7 are empty in both.

## The screens

- **Top menu:** "Play Live Show" (entry 0) and "Play Live Show (AC)" (entry 1) are both in the Play submenu. Today both open the same arcade song select.
- **Song select:**
  - offers only the five arcade difficulties (`kDifficulties = 5`);
  - its label atlas already holds BEGINNER-ADVENTURE (cells 0-3);
  - `ui2/20_setup` has an `uil0015_DifficultyList00_OR` layout (*Hypothesis:* the other mode's difficulty list).
- **Live:**
  - the ring positions come from `ui/ui_ingame.pac/layout.pac/ui_ingame_layout.bin` `layout_datas`, which holds only the nine arcade rings (`layout_judge_ring01`-`09`), the centre circle and the FULL COMBO banner. **No 6-lane ring layout is in the data**;
  - the 6 positions are then either the arcade positions of those six lanes, or positions the code computes;
  - the Button Controls picture puts L1 and R1 high at the ends, which matches arcade lanes 1 and 7 (`ring02`, `ring08`);
  - the atlas cell (3, 0), a blue ring, is unused so far (M7.5). *Hypothesis:* the home mode's L1/R1 rings, which are blue in the Button Controls picture;
  - `ui_ingame_judgering_band_aq` was noted as "the 3-lane band" in M7.5; that reading is open again.
- **Controls:** the port has the 9-lane Button Controls only. The 6-lane form (`button_6`, plates `_10`-`_15`, rings `_10`-`_15`) is not built.

## Eboot

- The live loader (`0x8F670`) and the note builder (`0xA08B0` → `0xABAC0`) were found in G0. The mapping from note number to lane for home charts is not traced yet.
- `0xA0940` (next to the builder) sets flags from counts at +0x04 to +0x24 of a note-count block. *Hypothesis:* simultaneous-note pairing.

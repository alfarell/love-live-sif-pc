# Home-version charts: the game run

Date: 2026-11-14 20:01 (Asia/Jakarta). This follows `202611141918-analysis.md` and answers its open questions from a shadPS4 run.

## Setup

- **Emulator:** shadPS4 (`work/shadps4-build/shadps4.exe`, v0.21.1 WIP) with `work/shadps4-run` as the working directory and its `user/` folder present. No file under `%APPDATA%\shadPS4` changed during the run.
- **New helper:** `work/scripts/shadpost.ps1` (not committed: `work/`). It replaces the lost `shadpost.ps1`:
  - `start`: launch shadPS4, refusing to start if `user/` is missing;
  - `key` / `keys`: posted only to the shadPS4 window, using the bindings in `user/input_config/default.ini` (✕ = N, ○ = B, L1 = Q, R1 = U, arrows);
  - `shot` / `series`: PrintWindow of that window only;
  - `run FILE`: a sequence of those steps;
  - `stop`: WM_CLOSE.
- **Route:** title → top menu → Play → **Play Live Show** → Susume→Tomorrow (0340) → HYPER → Live Show Stage → School Unity → Prepare (LIVE START) → live with no input → result.
- **Pictures:** `work/m10/shad/` (`h00`-`h12`) and the frame series `hyper2/` and `hyper3/` (4 per second, file names `NNNN_<ms>.jpg`).

## Answers

**1. The home song select** (`h08.png`, header "Play Live Show: Select Difficulty"):
- **Four difficulty cards:** BEGINNER, STANDARD, HYPER, ADVENTURE, with levels 3, 4, 7 and 11 for song 0340.
- **The bottom strip** shows the four save slots ("Unplayed"), with star bars of 10.
- **Focus:** on entry it is on STANDARD (the second card).
- **ADVENTURE is locked:** its card reads "Unlock by getting A or higher in HYPER" with a padlock (the M7 hint, now seen).
- **The other steps are as in the arcade mode:** Stage Selection, Select Costume, then "Prepare for the Live Show" with LIVE START (the port skips that last screen in both modes). The side panel shows "HYPER" with 10 stars.

**2. The six rings** (frame `hyper2/0130`, 1280 × 720, converted to the 1920 × 1080 canvas; centres from the orange rims):

| Lane | Button | Centre | Angle from (960, 150) | Arcade ring at the same spot |
|---|---|---|---|---|
| 0 | L1 | (135, 146) | 180° | ring01 |
| 1 | ← | (331, 680) | 140° | none (ring02 is 157.5°, ring03 135°) |
| 2 | ↓ | (644, 913) | 112.5° | ring04 |
| 3 | ✕ | (1276, 913) | 67.5° | ring06 |
| 4 | ○ | (1588, 680) | 40° | none (ring07 45°, ring08 22.5°) |
| 5 | R1 | (1785, 146) | 0° | ring09 |

- **The radius** is about 825 px, the same arc as the arcade rings.
- **← and ○ sit at 140° and 40°.** No table holding those angles was found: the layout file has only the nine arcade rings, and a float search of the eboot found unrelated tables. So they are measured constants (±1°).
- **L1 and R1 rings are blue**, with "L1"/"R1" plates and small stars; the other four are the usual orange-rimmed rings with their button icons. **No L2, R2 or centre ring is drawn.**

**3. Notes:**
- **Path:** notes travel in straight lines from the mic to their ring, as in the arcade mode. L1 and R1 notes run almost flat along the top edge (`hyper3/0030`).
- **Colours:** L1/R1 notes are **blue**; the others are pink with their button icon.
- **Pairs and holds** look like the arcade ones (bracketed pairs, hold trails).
- **Travel time:** HYPER is difficulty index 7, so 1000 ms at Normal (F3).

**4. Note number 0:**
- The result screen counts **MISS 414** (`hyper3/0140`, rank D).
- Channel 1 of `_12` has 389 note events, 2 of them note 0. Channels 2-4 add 27 notes. 389 − 2 + 27 = **414**.
- So **note-0 events are not notes**. The game does not count them, and the port's reader is right to skip them.
- *Hypothesis:* they are cues of some other kind (they also have lengths). Nothing visible was matched to them in this run.

**5. The result screen** is the arcade one, with the difficulty plate reading HYPER (star badge 7).

Date: 2026-11-25 22:53 (Asia/Jakarta). Step U3 of `plan/202611251725-m18-members-come-alive/202611251725-plan.md`. Follows U2 (`202611252236-analysis.md`).

## What the port does now

**A nameplate per mode** (U2: each L2 mode keeps its own):
- **Save:** `save::PlateChoice` and `SaveData::plates[2]` (0 µ's, 1 Aqours).
  - The file keeps the old lines `accolade`, `badge` and `name_plate` for µ's, so old saves load unchanged.
  - Aqours is a new line, `plate 1 A B N`.
- **Starters:** `MakeNameplate(..., mode)` (`app/main.cpp`) lists the mode's starters first, so a mode with no choice shows them:
  - µ's: accolade 2 新入生 and badge 901001;
  - Aqours: accolade 501001 助けて、ラブライブ！ and badge 902001.
  - Both modes also list the other starters, and Saint Snow's 800002 / 903001.
- **Top menu:** `RunTopMenu` takes both plates and redraws the header on L2.
- **Profile:** Change Accolade or Name Plate and Create a New Profile Card use the current mode's plate.

**The member loading splash** (`app/member_popup`):
- After a choice in the member box (R2 on the top menu and the costume screen, and 591's singers), the popup draws `00_common` `uip0072_ChrChangeSplash00` with `_charaTex_splash00` = `ui/ui_transition_character.pac` `com_load_mem00_<member>`.
- It plays clip a001 for 0.5 s; the last 0.15 s fade out.
- `IsOpen()` stays true meanwhile, so the callers keep drawing it and keys are ignored.
- The part's origin is the canvas corner, so it is drawn at (0, 0).
- None after L2, as in U2.

**The member card in "Check Costume"** (`app/costume_screen.cpp`):
- The box shows the member's R card, `card::ThumbPath(cards, member, costume)`.
- This helper was moved from `song_select.cpp` into `game/card`.
- The costume picture is still shown when there is no card data.

**The tutorial picture** (`app/top_menu.cpp`):
- **When:** the first start marks `tutorial_due` in the save, and the next top menu shows `00_common` `uil0066_TutorialPop00` once.
- **Picture:** `info00_M` = `ui/ui_tutorial_<lang>.pac` `tutorial_000_00_T` (µ's) or `_01_T` (Aqours). The base package is Japanese, so the language suffix matters.
- **Title:** `title00` is hidden (it shows for tutorial 1 only).
- **OK** closes it; then the day's login pop-up shows, as in the game (f11 then f12).
- **Routes see the screen `tutorial`.**

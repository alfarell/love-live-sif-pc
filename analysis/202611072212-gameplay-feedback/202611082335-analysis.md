## What this shows

1. **At the hit the size was already right.** The ring is 101 px in the game and 103 px in the port: `kNoteSize` 0.95 × 256 × the ring's 163/256 opaque width × 2/3. The second-round analysis (`202611082306`) compared the ring's inner pink width (150 px), which gave the wrong 0.80 ratio. This file corrects it.
2. **The difference is the growth curve.** Game notes leave the mic at about 0.8 of their final size and grow almost linearly to 1.0. The port grew them from 0.2. So in flight the port's notes were about half the game's size; at k = 0.42 the port had 55 px where the game has 91. This is the "smaller notes" in the user's image 1.
3. **Brackets:** in the game the span is 1.27-1.33 × the ring at every k. The bracket cell's own span-to-ring ratio is 202 / 163 = 1.24, so the game draws the bracket cell at about 1.05 × the note quad. The port drew it at 1.17, so its span was 1.45 × the ring.
   - Because the notes are now larger in flight, the brackets of a pair are also wider apart in absolute terms. The user asked for exactly this.
   - The 1.41 of G4 and the 1.46 measured in the user's image 2 disagree with these frames. *Hypothesis:* those were measured by eye on blurred stills and included the glow; the script values here are on clean frames.
4. **Bands narrow faster than notes.** In the frames the band is about 35 px wide at the mic, whereas a note there is about 80 px. So the hold tail keeps the old steeper curve.

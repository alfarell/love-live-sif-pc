  - the HUD shows the Aqours letters (anchors), five lit;
  - an icon note carries the two anchors.
- **Saint Snow** (song 1940 Normal, `g7_ss_62s.png`): the HUD shows the Saint Snow letters, six lit.

**Bug found and fixed:** the group letter textures were never loaded. The G5 path lacked the `.btx` extension (`ui: texture … no entry` in the log), so every group showed the µ's set. The fix is a one-line path change in `live_screen.cpp`.

- **Score without the finale:** song 0340 Normal all Perfect = 39,975 = the maximum (unit test). The finale factor is the only score change.

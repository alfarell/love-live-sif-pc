## Code

- **`src/game/live/chart.{h,cpp}`:**
  - `Note::group`: the simultaneous group, numbered 0, 1, 2 … in song order; -1 for a note alone;
  - `GroupNotes(Chart&)` sets it. Notes within 1 ms of the previous note share a group. `ParseChart` calls it; G5 calls it again after adding the extra channels.
- **`src/app/live_screen.cpp`:**
  - after each note, a grouped note draws `bracket[group % 2]` (orange, blue, orange …);
  - a held note sits on its ring with its brackets. This is the user's "vertical line" (the brackets' vertical parts) for a satisfied hold;
  - removed: `DrawBar`, the `bar` mesh and the joining-bar loop.
- **`tests/unit/live_test.cpp`:** `Groups()` checks the numbering, a 3-note chain within 1 ms steps, and lone notes.

## 3. What the names show (SIF eboot, `sif-dynlib-eboot.shadps4.csv`)

### Graphics: low-level GNM, the game builds its own command buffers

The 87 `libSceGnmDriver` imports are driver-level calls:

- Draws: `sceGnmDrawIndex`, `sceGnmDrawIndexAuto`, `sceGnmDrawIndexOffset`, `sceGnmDrawIndexIndirect`, `sceGnmDrawIndexMultiInstanced`, `sceGnmDrawIndirect`, `sceGnmDrawOpaqueAuto`.
- Compute: `sceGnmDispatchDirect`, `sceGnmDispatchIndirect`.
- Shaders: `sceGnmSetVsShader`, `sceGnmSetPsShader350`, `sceGnmSetCsShaderWithModifier`, `sceGnmSetEs/Gs/Hs/LsShader`, `sceGnmSetEmbeddedVs/PsShader`, `sceGnmUpdate*Shader`.
- State setup: `sceGnmDrawInitDefaultHardwareState350`, `sceGnmDrawInitToDefaultContextState400`.
- Submit: `sceGnmSubmitCommandBuffers`, `sceGnmSubmitAndFlipCommandBuffers`, `sceGnmSubmitDone`, `sceGnmRequestFlipAndSubmitDone`.
- Compute queues: `sceGnmMapComputeQueue`.
- Events: `sceGnmAddEqEvent`, `sceGnmInsertWaitFlipDone`.
- Debug markers and the Razor GPU profiler: `sceRazorIsLoaded`, `sceRazorCaptureImmediate`.

These write GPU command packets into buffers the game owns (GNMX-style helpers are linked into the eboot; Part 3 section 6). So an HLE port must **parse the PS4 GPU command stream (PM4 packets) and translate it**, which is what an emulator like shadPS4 does. The game also uses geometry/hull/local shader stages (`Set{Es,Gs,Hs,Ls}Shader`, `SetGsRingSizes`), i.e. tessellation or geometry shaders in some paths (Hypothesis: used or at least initialized).

VideoOut (13): `sceVideoOutOpen`, `sceVideoOutRegisterBuffers`, `sceVideoOutSetBufferAttribute`, `sceVideoOutSetFlipRate`, `sceVideoOutAddFlipEvent`, `sceVideoOutAddVblankEvent`, `sceVideoOutWaitVblank`, `sceVideoOutGetFlipStatus`, `sceVideoOutIsFlipPending`, `sceVideoOutGetResolutionStatus`, plus delete/close. That is a standard flip loop.

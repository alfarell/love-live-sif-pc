# M6: song select (20_setup), first version; the playable loop

Created: 202611020043 (Asia/Jakarta). Follows `202611020029-analysis.md`.

## 1. Survey of `ui2/20_setup_en`

- 29 layouts, 89 parts (with borrowed ones), 28 clips, 53 texts.
- Root: `uil0001_StepLayout00`, one layout for every setup step. It holds:
  - background, belt, group tab, title (`uip0002_StepTop00`, "Play Live Show: Select Song");
  - character preview, page markers;
  - song list `uil0013_MusicList00` (11 plates `uil0030_SelectPlate00_00`…`_10`: 00 in the centre, odd numbers left, even right);
  - difficulty lists `uil0015` (home, 4) and `uil0016` (arcade, 5);
  - the right-hand selection panel `uip0004_SelectList00`;
  - the song info panel `uil0010_MusicSelect00`;
  - stage and costume steps (`uil0020`, `uil0025`), the Live View popups (`uil0070`–`0072`), the ticker.
- Each song plate holds the music part `uip0013_MusicSelect00` plus a stage and a costume part (other steps reuse the plate).

## 2. Eboot

The setup screen code is at **0x163000–0x179000**, a large class. The functions using the plate names:

| Function | Size | Role |
|---|---|---|
| `0x168630` | 128 KB | Plate and step update: `select_bg00_on/off`, ranks, group logos, status marks |
| `0x16D960` | 20 KB | Song plate / info refresh |
| `0x162C90` | | Difficulty stars |
| `0x164850` | | Stage layout and `M_cd_cover` |
| `0x178880` | | Start and menu buttons |

From `0x16D960`:
- The **cover** comes from `FUN_0024B850(plate, "cd_cover00")` (material lookup), then a texture named from the song id. The covers are `ui/ui_music_thumbnail.pac/texture.pac/cd_cover_NNNN` (126 files).
- The **credits** are `FUN_005DDD80("%s\n%s\n%s", …)` of `s_music_datas` +0xD0 (lyricist), +0x90 (composer) and +0xB0 (arranger). Each field holds 4 language pointers (Japanese, English, simplified Chinese, traditional Chinese).

Text boxes (`ui_text.bin`):
- part 13 (song plate) box 0 = song name;
- part 10 (preview) box 0 = name, box 3 = credits;
- part 4 (selection panel) boxes 0–2 = song, stage, costume.

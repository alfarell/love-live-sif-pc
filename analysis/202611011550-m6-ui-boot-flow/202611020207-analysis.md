# M6: HUD rank gauge (clear rate)

Created: 202611020207 (Asia/Jakarta). Follows `202611020158-analysis.md`.

## 1. The part

`ui2/90_ingame` part `uip0002_Ingame00Topscgage` (in `uil0001_Ingame00`) has three meshes:

| Node | Texture, UVs |
|---|---|
| `Ingame00Topscgagebase` | `ingame_score_gagebase` (the empty track) |
| `Ingame00Topscgage` | `ingame_score_gage00`, U 0–1, V 0–0.125: one colour row of the bar |
| `Ingame00Topscrank` | the same texture, the C/B/A/S letter strip (V 0.687–0.746) |

`ingame_score_gage00` (800 × 512) holds the full bar in 5 colour rows (blue, green, yellow, orange, pink), each 1/8 of the height. Measured on row 0:
- the bar spans x 31–768 (U 0.039–0.961);
- the divider gaps are at U 0.379, 0.536, 0.672, 0.751.

## 2. Rank thresholds and the bar

U5 (`analysis/202611010903-u5-live-rules/202611010917-analysis.md`) found that clear rate = score / maximum score (+1e−5). It is compared with `s_CommonParam` +0x138…+0x14C = 0.45, 0.65, 0.825, 0.925, 1.025, 1.2.

Measured from the bar's start, the dividers sit at 0.369, 0.538, 0.686, 0.771 of the bar. These are 0.82–0.83 × 0.45, 0.65, 0.825, 0.925. So the dividers mark the first four thresholds, and a full bar is a clear rate of 1.2, the last threshold. This fits a linear bar, U = 0.039 + 0.922 × min(rate / 1.2, 1).

The colour row per rank (blue below the first threshold, then green, yellow, orange, pink) is a *Hypothesis*.

## 3. Port

- `ScoreRules::rank_rates` is read from +0x138…+0x14C. `LoadScoreRules` now needs `s_CommonParam` ≥ 0x150 bytes.
- New in `Judge`:
  - `MaxScore()` (eboot 0xA94F0): every judgement at Perfect (holds count press and release) plus every hold tick, capped at 9,999,999;
  - `ClearRate()`;
  - `Rank()`: the number of thresholds reached.
- Renderer: `ui.frag` drops fragments whose mesh U exceeds `uv_offset.z`. `DrawUiMesh` gains a `u_max` (default 1e9). `UiScreen::SetMaterialClip(instance, material, u_max)` sets it per material; it shares the per-material entry with `SetMaterialUv`.
- `RunLive` sets the gauge fill and colour row whenever the score changes.
- **Tests** (`tests/unit/live_test.cpp`):
  - all-Perfect score = `MaxScore()`, for the synthetic chart and song 0010/04;
  - ranks 4 and 0 for the synthetic plays;
  - thresholds read as 0.45 … 1.2.
- **Check:** `work/m6/rank_a.png` was taken 60 s into song 0010 on autoplay (score 85620 of 199220 maximum, rate 0.43). The blue bar ends just before the C divider. All 5 tests pass.

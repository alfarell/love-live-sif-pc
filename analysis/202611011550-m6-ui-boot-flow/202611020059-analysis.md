Created: 202611020059 (Asia/Jakarta). Follows `202611020049-analysis.md`.

## 1. Number boxes (`ui_number.bin`, `numtex_datas.bin`)

Each ui2 package can carry two `BLBN` tables for digit strings drawn from a number texture.

| Table | Record |
|---|---|
| `ll3::ui::s_ui_number_info_table` (`ui_number.bin`) | 24 bytes: u32 part id, u32 box \| numtex id << 16, u32 digit count << 16, u32 alignment, u64 default string\* |
| `ll3::ui::s_ui_numtex_datas` (`numtex_datas.bin`) | 200 bytes: u32 id, u32 0, u64 texture name\* (`*.png`), f32 x0, y0, cell w, h, u64 0, 20 × (f32 advance, u32 0) |

- "Box" is the index of the part's untextured quad (as for text boxes).
- Texture names end in `.png`; the `texture.pac` entries are named `<stem>.btx` (the entry name already has the extension), so the port looks up `<stem>.btx`.
- Glyphs run left to right and **wrap at the texture width**: `res_judge_num00` has 0–4 over 5–9; `res_record_num00` is one row.
- Alignment: the port treats 0 left, 1 centre, 2 right (*Hypothesis*; the result screen uses right-aligned boxes).

## 2. Result screen (`ui2/95_result`)

- Root `uil0001_ResultTop00`, layout `uil0002_ResultLayout00` (18 layouts, 49 parts, 28 clips, 27 texts).
- `uip0003_PlayScore00` in `uil0005_PlayScoreWin00`: number box 0 = play score, box 1 = max combo; box 2 (*Hypothesis:* clear rate) left empty.
- `uil0006_JudgNumberList00` places 5 rows `uip0006_JudgNumber00_00…04`. Each row's number box 0 is the count. Its label `Judg_text00_M` uses the atlas `res_judge_text00`, which stacks PERFECT, GREAT, GOOD, BAD, MISS in five rows. The part has only an "in" clip, so the row must be chosen by code; the port shifts V by k × 0.2 (*Hypothesis*: the eboot routine is not traced).
- `uip0002_SongData00`: box 0 = song title, material `cd_jacket00_M` = `ui/ui_music_thumbnail.pac/texture.pac/cd_cover_NNNN`.

## 3. Port

- `UiScreen`:
  - reads both tables at load (`SetInstanceNumber` sets one instance's digits);
  - `SetMaterialUv(instance, material, u, v)` shifts a material's UVs per instance; clip ANMT tracks still win over it.
- `RunResult` (`src/app/result_screen.cpp`) fills score, max combo, the five counts, title and cover, then waits for a key.
- `RunLive` fills a `LiveResult`. The boot flow shows the result after a finished song. `--result-demo` shows it with fixed values.

# M6: note face by the song's group

Created: 202611021656 (Asia/Jakarta). Follows `202611021648-analysis.md`.

## 1. `s_music_datas` fields (live_datas.bin)

All 125 records were printed with their English titles, words +0x00…+0x44:

| Offset | Values | Meaning |
|---|---|---|
| +0x00, +0x04 | the song id, twice | id |
| +0x0C | 2000–3180 | unknown |
| **+0x10** | 0 for ids 10–720, 1 for 1010–1550, 2 for 1900–1940 | **group**: μ's, Aqours, Saint Snow (SELF CONTROL!!, DROPOUT!?, Believe again, CRASH MIND) |
| +0x14 | 0, 1–3, 5 / 4, 7–9, 6 / 10 / −1 | unit: μ's full group, μ's sub-units, μ's solos / Aqours full group, Aqours sub-units, Aqours solos / Saint Snow / mixed line-ups |
| +0x18 | 1–11 | member count (already known) |

The group and unit readings follow the titles. For example, the μ's solos ("Kodoku na Heaven", "Daring!!") have unit 5 and 1 member; "Awaken the power" (Aqours with Saint Snow) has 11 members.

**Mistake caught:** the first version read the group from +0x0C. I had misread my own dump, where the first printed column was the id and the following columns started at +0x04. Every song then showed the snowman. Captures plus a new live test (song 1020 must be group 1) caught it; the offset is now +0x10.

## 2. Port

- `live::Song::group` is read with the dance start in `LoadMusicRecord` (renamed from `LoadDanceStart`, its only caller being `LoadSong`).
- `Playfield::Load` picks the note face from atlas row 1 by group: star, anchor or snowman (*Hypothesis*: the faces match the groups' symbols, but the game's choice is not traced).
- Docs: `repository/docs/formats/blbn.md`.
- Tests: `live_test` checks song 0010 as group 0 and song 1020 as group 1.

**Check:** `work/m6/faces.png` shows songs 0010 (stars), 1020 (anchors) and 1940 (snowmen) on autoplay. Debug and Release are rebuilt, and all 7 tests pass.

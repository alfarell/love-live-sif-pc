# M6: the core loop (song select ↔ live ↔ result)

Created: 202611020106 (Asia/Jakarta). Follows `202611020059-analysis.md`.

## 1. Flow (`src/app/main.cpp`)

```
title -> top menu -> song select -> live -> [result] -> song select -> ...
                ^          | Esc
                +----------+
```

- A song played to its end shows the result; any key goes back to the song select.
- Esc during a live goes straight back to the song select (no result).
- The song select focuses the last song and difficulty again (`RunSongSelect(..., previous)`).
- Esc in the song select returns to the top menu (or ends with `--select`, which has no menu). Esc in the top menu ends.
- Closing the window ends from any screen. `SongChoice::closed` and `LiveResult::closed` tell a closed window apart from Esc.

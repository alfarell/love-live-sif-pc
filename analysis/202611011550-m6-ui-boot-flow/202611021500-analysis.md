- It fades out to black at either end:

- `fade.Leave` plays `a002` on the HUD's instances (`ui2/90_ingame`). Whether those parts have "out" clips was not checked; parts without one are unaffected.

The whole boot flow (title → top menu → song select → live → result → song select) now changes screens through a fade.

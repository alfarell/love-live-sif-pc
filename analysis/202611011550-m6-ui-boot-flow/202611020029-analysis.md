## 2. Labels come from the "switch" clip

The update function `0x1BD2D0` does this for each submenu banner:

```c
FUN_0024bd10(0, banner, 20, 1);            // play clip 20 "switch" on layer 1
FUN_004b4790((float)entry_id, banner, 1);  // layer 1 time = the entry id
```

The wheel icons (`0x1B94C0`) do the same with time `((wheel position + 3) mod 6) + i` for icon i of 8.

The switch clips animate `ANMT` types 4/5, which this settles as **U/V offsets**, not transparency. For example `uip0005_SubMenuList00_a020` steps U by 0.25 and V by 0.125 over a 0.25 × 0.125 atlas cell, so **frame N = atlas cell N**.

The wheel's switch clip (`uip0004_MenuList00_a020`) has 6 labels (frames 0–5), while the icons ask for frames 3–10. The engine must wrap past the end (*Hypothesis:* modulo length + 1). With that wrap, the 6 labels come out in the game's order. The format doc is corrected (`docs/formats/bmar.md`).

## 3. Mode and entry tables

| Data | Address | Content |
|---|---|---|
| Submenu list per mode | `0x5F42F0` | 1, 3, 3, 1, 0, 2 |
| Entries per list | `0x5F3F54` | 5, 4, 3, 2 |
| Entry ids per mode | pointers at `0xC085A0` (resolved via the relocation records) | mode 1 [0, 1], 2 [5, 7], 3 [8, 9, 10, 12], 4 [10, 12, 13, 14, 15], 5 [15, 16, 17]; mode 0 is filled at runtime |
| Entry available | `0x5F4430` | per id |
| Visible list | code | idle lists `+0x3C8…`: shown for mode 4 / 0, 3 / 5 / 1, 2; active lists `+0x3E8…` |

- **Placed instances by id:** `FUN_00249BA0(out, list, part id, instance)` finds the placed instance with key `part id × 100 + instance`. For example (5, i) is `uip0005_*_0i` and (6, i) is `uip0006_*_0i`.
- **Lists ↔ layouts:** matched by banner count (5, 4, 3, 2): 0 → `uil0003`/`uil0006_act`, 1 → `uil0010`/`uil0011_act`, 2 → `uil0004`/`uil0007_act`, 3 → `uil0005`/`uil0008_act`.
- **Mode 0** (*Hypothesis*, now visually confirmed): ids 0–3 at 0x5F4410. With them, its submenu reads "Play Live Show, Play Live Show (AC), View Live Show, Live Show Medley", exactly the menu seen in shadPS4 (M4).
- **Wheel order** (mode → label): 0 Play, 1 Costumes, 2 Additional Purchase, 3 Options, 4 Collection, 5 Event.

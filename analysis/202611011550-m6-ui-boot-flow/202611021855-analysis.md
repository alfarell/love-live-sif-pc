# M6: costumes in the live

Created: 202611021855 (Asia/Jakarta). Follows `202611021815-analysis.md`.

## 1. Where costumes are

- `chr/cNN/cNN.pac/model.pac/mod_NN_<name>` is the **base model**: body, face, hair and eyes, with the plain "dummy body" outfit (`*_dumbody_*` textures). The port drew this until now.
- `chr/cNN/dXXX/dXXX.pac` (some also `dXXX_v1.pac`) holds one **costume**:
  - `mod_NN_<name>_XXX_<tag>`, e.g. `mod_01_honoka_001_bokuima`;
  - `texture.texs` with the costume's own textures (`…_tops/btms/legs/acce/arms_…`);
  - `dynamics.dyns` (cloth or hair physics data, not used).
- The costume model is a **complete member**: `Honoka_body`, face, hair, eyes, plus `c01_hnk_bkim_tops/btms/legs/arms/acce` and `unified_mesh`. Its face and hair materials name the base textures (`honoka_body_01`), which are only in the base `model.pac/texture`.
- **Folders:**
  - μ's members have d000–d060 (not all members have all costumes; e.g. Honoka has no d025);
  - Aqours members have d000, d090–d160;
  - Saint Snow have d200, d217, d260, d999.
- **d000** is the school uniform (blazer; `work/m6/costume_d000.png`). It is not in the costume table.

## 2. Costume table (`common/dress.pac/dress_data.bin`, `ll3::dress::s_dress_datas`)

- 192-byte records; record 0 is empty (id −1). +0x00 is the costume id = the `dNNN` folder = the thumbnail `ui/ui_dress_thumbnail.pac` `dress_thumb_NNNN`. Names in 4 languages follow at +0x08 (English at +0x10).
- 70 costumes, in the game's order: 31 "Bokura no LIVE Kimi to no LIFE", 4 "Snow Halation", … 260. Many are named after a song.
- The later fields look like group and category flags (e.g. +0x50 = 1 on Aqours costumes) and member lists; not decoded.

## 3. Port

- `SceneModel::Load(…, more_textures)` searches one more texture folder last.
- `LiveOptions::costume` (`dNNN`, flag `--costume`): each member with `chr/cNN/dNNN/dNNN.pac` loads that model, with its base `model.pac` as the extra texture folder. Members without it keep the base model.
- `live::LoadDressList` and `live::PickCostume`: when no costume is given, the live uses the costume named like the song (English names) if every member has it. Otherwise it uses d000 if everyone has it, otherwise the first costume in table order that everyone has. This rule is the port's own (marked as a `shortcut:`): the game's costume step lets the player dress each member, and it is not built.
- **Tests** (`live_test`):
  - 70 costumes, first 31;
  - Snow Halation → d004;
  - Natsuiro Egao (no costume of its own) → d000;
  - CRASH MIND → a d2xx costume.

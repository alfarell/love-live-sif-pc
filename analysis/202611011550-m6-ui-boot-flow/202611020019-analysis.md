- The strings `TopMenu` (0x5F80F8), `room_bg000`/`001`, `event_info00`, `new00`, `complete00`, `logo_ms00`/`aq00`/`ss00`, `player_data_bg00_*` and `_charaImage%02d` are used only by code at **0x1B8790–0x1BF7xx**.
- The scene names `sqTopMenu`/`scTopMenu` are nearby in the strings (0x5EA691…).

| Function | Size | Role (from the decompile) |
|---|---|---|

| `0x1B94C0` | 81 KB | Input and update: plays clips on the icons and submenu lists; `new00`/`complete00` per entry |
| `0x1BD2D0` | 52 KB | Refresh: room background (`room_bg000`/`001`), unit logos (μ's / Aqours / Saint Snow), player-data plates, event info, badges. The **6 wheel entries** are indexed mod 6; unselected entries get colour `0xFFC0C0C0` (written to instance +0x5C) |
| `0x1BF6A0` | small | Fills `_charaImage%02d` nodes with character images |

## 2. UI runtime calls (the game's own UI API)

| Function | Signature (reconstructed) | Meaning |
|---|---|---|
| `0x24BD10` | `(f32 rate, instance, u32 clip, u32 layer)` | **Play clip `aNNN`** on an animation layer. Looks the clip id up in a table (`FUN_00246FA0`; the flag at +0x10 is probably "loop", *Hypothesis:* 00_common `ui_animation.bin`). Stores clip, flag and rate per layer at instance +0x158 + 12 × layer. The top menu plays clips 1, 3, 4, 5, 9, 13, 20 |
| `0x24B8E0` | `(instance, "node", u16* index)` | Finds a node of the instance's part by name (0xF0-byte node records at +0x1C0) |
| `0x4739C0` | `(node, visible, recursive)` | Sets or clears a node's visibility flag bit (0x2), recursively over its children |
| `0x4B4790` / `0x4B4800` | `(value, instance, layer)` | Set field +0x0C / +0x14 of an animation layer (*Hypothesis:* time and speed) |
| `0x4B48D0` | `(instance, layer)` | Read field +0x10 of a layer |
| `0x249BA0` | `(out, context, a, b)` | Resource lookup by key `context id × 1,000,000 + a × 100 + min(b, 99)` (*Hypothesis:* textures or parts by id) |

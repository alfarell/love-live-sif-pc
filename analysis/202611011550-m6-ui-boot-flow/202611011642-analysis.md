## 2. Port

- **stb_truetype v1.26**, chosen by the user over FreeType and SDL3_ttf. It is in `third_party/stb/`, recorded in `THIRD_PARTY.md`, and compiled once (`src/engine/ui/stb_truetype_impl.c`, its own target with warnings off).
- `UiText` (`src/engine/ui/ui_text.{h,cpp}`):
  - loads the style table and the fonts (each one on first use);
  - renders a UTF-8 string into a straight-alpha BGRA bitmap, with kerning, spacing and a dilated outline under the fill.
- `UiScreen`:
  - reads `ui_text.bin`;
  - draws each string into its part's text box: the untextured quads, numbered in draw order (`SceneModel::TextBoxes`);
  - aligns by style, with size 0 = box height;
  - renders the bitmap once and draws it as a blended quad;
  - `SetText` replaces a string.
- **Check:** the title shows "Version 1.01" at the bottom right, dark grey with a white outline (style 97 → font 5 `NPSeurat-DB`, `#323232`, outline `#ffffff`), inside the copyright part's `_text00` box (`work/m6/title_text.png`, not committed).

  The font, colour and outline match the style fields, which supports the field meanings above for this style. The alignment fields are not yet tested against a game screenshot.
- All 5 tests pass.

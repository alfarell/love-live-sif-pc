# M6: `message.pac`, second look (paused)

Created: 202611021703 (Asia/Jakarta). Follows `202611012335-analysis.md` §2 and `202611021701-analysis.md`.

## 1. What was checked

- `message/message.pac` was extracted to `work/extract/message/` (4 language packages, `0000.pac`–`0003.pac`).
- `pac_extract.py` does not open the language packages: each starts with u32 4 before its `ARC\0` table. Opening them by hand (skip 4 bytes) gives 816 tables per language.
- **The "unknown English encoding" is not an encoding.** The English text is plain ASCII ("New Player", "Guest player", "Unregistered …", "English Not Defined"), preceded by repeated 8-byte markers `df 07 0a ff 00 00 00 00` (*Hypothesis:* per-line style or colour codes).
- **The archive entry sizes are short for these tables.** Table 6's entry (83 bytes) ends at "New Pla", but the file continues "New Player\0\0", then the next table's block. All texts read through the generic ARC framing are cut after about 16 characters ("English Not Defi"). The block header before the next table does not match the usual u32 size, u16 header length, u16 flags layout either. So the framing of `message.pac` entries differs from the other archives. The engine's `Vfs` probably cuts them too (not tested).
- Table layout (English tables 6 and 7):
  - u32 4, u32 0, u16 index size (0x48, 0x60), u16 × 3 row count (10, 12);
  - u16 pairs (flag, self-relative offset);
  - then the marker runs and the text.
  - The Japanese tables of the same index are smaller and have different row counts.

## 2. Why it is paused

Using this text needs three things:
1. the correct entry framing;
2. the per-table index decoded;
3. which table and row each UI text box uses, which the eboot decides (not traced).

The visible gain in the current screens is small: the header placeholders (player name, date, item counts) and a few labels. Most menu text is images. This is weighed against other M6/M7 work in the next plan step.

## 3. If resumed

- Find the true entry sizes, either from the block header (compare all 816 tables) or from the text NUL ends.
- Fix `pac_list.py`/`pac_extract.py` and `Vfs` for this framing, with a test.
- Trace the eboot's message lookup (the "English Not Defined" placeholder string is a likely anchor).

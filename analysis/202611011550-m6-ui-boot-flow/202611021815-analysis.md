## 2. Stage step

The step order is now song → difficulty → **stage** → start; Esc goes back one step.
- **Plates:** the song list's 11 plates switch to their `uip0040_StageSelect00`, with the thumbnail (`stage_thumbnail00_M`) and the name (text box 0).
- **Preview** (`uil0020_StageSelect00`): `uip0041` shows the focused stage's thumbnail as its picture, and the name on its tape. `uip0043` (records) is hidden without a save, and so are the song step's difficulty cards behind the preview.
- **Panel:** the selection panel's "Selected Stage" picture (`stage_000`) and text box 1 show the chosen stage.
- **Defaults:** the stage starts on the last choice, else `st017` (the live screen's default). The choice goes to `LiveOptions::stage`.

## 3. Engine fix: missing textures are not text boxes

`uip0041`'s picture material names `stage_preview00`, which is not in the dump; the game must fill it at run time. `SceneModel` treated any mesh without a loaded texture as a text box. As a result, this picture became text box 0, the stage name was drawn into the whole 750 × 380 picture area, and the override texture was never drawn.

- **Now:** a text box is a mesh whose material names no texture. A named-but-missing texture is drawn when the caller supplies one (`SetMaterialTexture`), and skipped otherwise.
- **Recheck:** the result screen (`work/m6/recheck_result.png`) and the live HUD (`recheck_live.png`) are unchanged.
- **Also new:** a text line wider than its box is scaled down to fit (*Hypothesis* on the game's rule).

## 4. Result difficulty

It also uses `res_difficulty_star_plate00` (five colour discs, EASY … CHALLENGE; `star_bg00_M`) and the `00_common` level badge in `uil0005_PlayScoreWin00`. They now show the played variant instead of BEGINNER. `work/m6/result_stage_check.png`: CHALLENGE(AC), purple, level 11.

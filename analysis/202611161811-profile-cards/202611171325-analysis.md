# P4d: End the Live Show (and P4 close)

Date: 2026-11-17 13:25 (Asia/Jakarta). Part P4d of `plan/202611161811-m12-profile-cards/202611162142-plan.md`. Follows P4c (`202611171255-analysis.md`). Reference: shadPS4 shots `work/m12/shad2/v12`, `v13`.

## Change

**`RunLiveViewEnd`** (`src/app/result_screen.cpp`) shows "End the Live Show" after a View Live Show that took photos. It uses `ui2/95_result` `uil0020_LiveEndLayout00`:
- **Header:** "View Live Show:" and "End the Live Show" (cells of `res_title_text00_T` / `01_T`, row 3 of 4 each).
- **Song plate** (`uip0040_SondData01`): the cover, the title, "Stage / Costume:" (message 567; the part's own text is a Japanese placeholder), the stage thumbnail (from the stage folder via `s_stage_datas`) and the played member's R card.
- **Photo list** (`uip0041_PhotoList00`):
  - "Photos taken this time: n" (message 575);
  - the focused photo large;
  - the photos in the five small frames, with the focus mark (`_eff`) on the focused one;
  - one favourite mark each (`uil0021_LiveEndCheckMark`, `com_favorite_icon00`: off at u = 0, on at u = 0.5).
- **Keys:** ←/→ pick, □ (Q) marks a favourite, Enter or Space ends.
- **Logs:** `live end: N photos`, `live end: photo N favourite on|off`.

**Saving** (`src/app/main.cpp`): the photos are saved after the End screen, as before, now with the favourite flag (`photo … 1`). A closed window saves them too and then ends.

**Engine:** `SceneModel::DrawUi`'s texture map also takes a node name as the key, and it wins over the material. The five small frames share one material, so each frame needs its own picture by node.

**Shortcuts** (in code comments):
- **"What will you do next?":** the game's box after the End screen (Close the Window, Play Live Show Again, Return to Song Selection, Return to Main Menu) is not built. The port has no such box after Play Live Show either; the song select comes back, as after a played live.
- **The 3D member on the right** (`uip0042_ViewChara00`) is not drawn; the port's menus have no 3D members.
- **The ticker's help line** ("Set your favorite photos.", message 425) is not shown. No port screen fills the ticker yet.
- **The "no image" case:** the screen is shown only when photos were taken (whether the game shows it with none is not known).

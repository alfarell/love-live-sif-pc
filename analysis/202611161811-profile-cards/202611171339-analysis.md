# P5: Collection → Photo Gallery and Member Card

Date: 2026-11-17 13:39 (Asia/Jakarta). Step P5 of `plan/202611161811-m12-profile-cards/202611161939-plan.md`. References: shadPS4 shots `work/m12/shad2/c01` (gallery), `work/m12/shad/c07`-`c11` (member cards).

## Change

**New `src/app/collection_screen.*`.** Both screens use `ui2/40_collection` `uil0001_CollLayout00` with the shared window `uil0011_GalleryComWin00` and its list `uil0022_CollSelectList00`:
- the list's `card00` group: 42 member card cells, 7 to a row, 240 apart;
- its `photo00` group: 56 photo cells, 7 to a row, 144 apart.

The title row comes from `col_title_text00_T` (rows of 1/8: Member Card 0, Photo Gallery 0.25).

**Collection → Photo Gallery** (top-menu entry 18):
- **The grid:** the saved photos, newest first, 7 to a row. The grid is moved down 184 px so its first row sits where the game's does (shad2 `c01`). All 30 photos fit rows 0-4, so there is no scrolling.
- **The thumbnails:** each photo read back from `photos/NN.png` at a quarter size.
- **Favourites:** a green mark on favourites only (as in `c01`), and the counter "Favorites: n (Maximum Number: 25)" (messages 796, 798).
- **Keys:**
  - arrows move;
  - □ (Q) toggles a favourite, refused past 25;
  - Delete removes a photo that is not a favourite: the file and the save line (message 800's rule);
  - Space or Enter shows the photo full screen, and any key closes it;
  - Esc leaves.
- **Saving:** the save is written when the screen closes.

**Collection → Member Card** (top-menu entry 16):
- **Tabs:** the member tabs (L1/R1 = Page Up/Down; Tab switches µ's / Aqours and Saint Snow), as in Collection → Skill Card.
- **The grid:** the member's R member cards, one per costume, in table order.
  - **Owned** (the costume is owned, `costume::Owns`): face up, `mbc_<id>`.
  - **Not owned:** the card back.
- **Paging:** the three rows inside the window, as in the skill collection.
- **The window title:** the costume name, or "(Not possessed)<name>" (message 490).
- **Log:** `member cards: member M, N cards, K owned`.

**Engine:**
- `png::Read` reads the port's own PNGs (8-bit RGBA; filters 0-4 undone; other PNGs fail).
- The menu pad layout maps □ (West) to Q.
- The route player knows the keys `delete` and `tab`.

**Note on ownership:** costumes from the user's installed add-ons count as owned, so with the user's add-ons Honoka owns 32 of her 33 cards. The shadPS4 save had no add-ons and owned one. This is the same rule as the song select's costume list (M11).

**Shortcuts** (in code comments):
- **Member Card's enlarged view** (✕ in the game: card number "M-0056", □ Frame ON/OFF, previous/next) is not built. The large card is drawn from several per-member textures (`ui_member_card` `mbc_<member>_top`, backgrounds, costume-name atlases) that are not decoded.
- **Delete** does not ask first (the game asks with message 799).
- **No photos:** the window shows "No photos." in English.
- **Thumbnails:** unfiltered.
- **The touch pad** (Delete on a pad) is not mapped.

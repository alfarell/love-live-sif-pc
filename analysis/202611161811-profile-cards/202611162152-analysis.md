# P4a: View Live Show, the flow

Date: 2026-11-16 21:52 (Asia/Jakarta). Part P4a of `plan/202611161811-m12-profile-cards/202611162142-plan.md`. Reference: the shadPS4 shots `work/m12/shad2/v01`-`v13` (P2 retry).

## Change

**Top menu → Play → View Live Show** (entry 2) now opens a view mode instead of the arcade song select (`src/app/main.cpp`). The viewed live records nothing, drops nothing and shows no result. Afterwards the song select comes back.

**Song select in view mode** (`src/app/song_select.cpp`, `RunSongSelect(..., view)`):
- **Header:** "View Live Show" (`title_mode00` row 3) with the pink page names.
- **Song step:** the "LIVE VIEW MODE" banner (`uil0070`) in place of the difficulty cards, and the no-materials note (`uil0072`).
- **Steps:** song → stage → costume → Prepare. There is no difficulty step; Esc goes back the same way.
- **Prepare:** the camera-mode help panel (`uil0071`, µ's or Aqours text), the note and LIVE START. The profile, skill and booster parts and the sub-buttons are hidden.
- **The chart:** variant 11, the home STANDARD chart. The game's photo records name live 340011 = song 0340, variant 11.
- **Shortcuts** (in code comments):
  - The selection panel's difficulty row is hidden and leaves its gap; the game's panel has no difficulty box there.
  - The "photo store is full" note (`uip0073`) stays hidden.

**The live in view mode** (`src/app/live_screen.cpp`, `LiveOptions::view`):
- **What it shows:** the stage, the members, the stage screens and the song's camera. There is no play field, judge, judgement sound or score.
- **The HUD** is `ui2/90_ingame` `uil0002_LiveView00`:
  - the camera bar "Camera: R1 MV » Member » View" with the current mode lit;
  - Take Photo / Info ON/OFF;
  - "Photos 0/5";
  - the song name;
  - the Member camera's help and member icons, in Member mode.
- **Keys:**
  - R1 (Page Down) cycles the camera mode. The mode is shown and logged; the cameras themselves come in P4b.
  - □ (Q) hides the whole HUD.
  - Esc leaves.
- **The end:** the live ends when the music stops (`live view end`). The End screen comes in P4d.
- **Shortcuts:**
  - the MV mode's help part (L1 "Launch Finale Focus") is hidden, as in the game's MV shots; Finale Focus is not built;
  - "Photos" is the English label in every language.

**Pad keys** (`src/app/input.*`): a new `PadLayout::View`:
- D-pad = arrows; Circle = P (Take Photo); Square = Q; L1/R1 = Page Up/Down; L2/R2 = Home/End; Start = Esc.
- The route player knows the keys `q`, `p`, `home` and `end`.

**Engine fix, UI text boxes** (`SceneModel::TextBoxes`):
- **The bug:** a part whose only text mesh is `_text01` (`uip0005_Songname`, where ui_text names box 1) got that mesh as box 0, so its text was never drawn.
- **The fix:** when a `_textNN` number does not fit the mesh order, the boxes are placed by their numbers. Parts whose numbers already fit are unchanged.
- **Effect:** the song name now shows at the bottom right in View Live Show and in the normal live HUD (route `live_mus`). Before, it was missing in both.

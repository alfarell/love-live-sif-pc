Date: 2026-11-17 17:33 (Asia/Jakarta). Step P7 of `plan/202611161811-m12-profile-cards/202611161939-plan.md`. Follows P6b (`202611171450-analysis.md`). Reference: shadPS4 `work/m12/shad/intro/` (`0012_012033.jpg`).

## Change

**New `src/app/live_intro.*`, `RunLiveIntro`:** the screen before a played live (not View Live Show), from `ui2/90_ingame` `uil0010_LiveStart00`. It shows:
- the song title on black;
- **the player's panel** (`uip0054_PlayerCard00`):
  - the played member's R member card in her costume;
  - her three set skill cards, with card backs for empty slots;
  - the nameplate.
- **"Profile Card Support"** (`uip0056_UserProc00`, message 814): "(NPC Profile Card)" (815) over two cards and three "Skill not set." rows each (684; the presets set no skill cards).
- **Hidden:** "Profile Card in Use" (`uil0013`; received cards, none offline) and the automatic-skill list (`uil0020`).
- **Timing:** it lasts 4 s, or ends with Enter or Space. Then the live starts.

**The NPC pick** (`main.cpp`):
- `profile::PickSupport` with the eboot's group filter: µ's for a µ's song, else Aqours and Saint Snow;
- one `XorShift128` per game run, as the eboot;
- **log:** `live intro: '<song>', member card N, skills a b c, support <X>'s fan and <Y>'s fan`. The route's first live got Umi's fan and Rin's fan.

**Engine:**
- `UiScreen::TextBoxesByName(part)` lets one part place its text boxes by their `_textNN` names instead of the mesh order.
  - **Why:** `uip0056_UserProc00`'s meshes run `_text01`, `_text00`, `_text02`, and ui_text gives box 0 (the header) its own style.
- **Not engine-wide:** a scan of every UI part (`work/m12/textbox_scan.py`) found 36 parts whose order would change, among them the song select panel, Prepare's profile box, the skill info window and the mission plates. The port fills those by the mesh order it probed, so the rule is opt-in.

**Shortcuts** (in code comments):
- **The skill cards' "Lv.n" labels** in the player's panel are not filled.
- **The intro's own animation** (the support panel slides in later in the game) is not played.

**Docs:**
- **`docs/PLAY.md`:** View Live Show and photos, Collection (Photo Gallery, Member Card, Profile Card), the profile card editor, the live intro, the new keys, and the "not built" list.
- **`docs/CHECKLIST.md`:** a new M12 section with 9 items for the user; the Profile Card item notes the new menu.

## The NPC pictures: stb_image (added with the user's approval)

- **The pictures:** whole rendered cards, `proca_preset/<photo>` in the dump (672 × 1100 JPEG), with the language's `_en`/`_cn`/`_tw` variant (Japanese without).
- **First:** the port had no JPEG decoder, so the slots stayed empty.
- **The user approved adding `stb_image.h`:**
  - v2.30, the official repository, commit `013ac3be` (2024-05-31), unchanged, SHA-256 in `THIRD_PARTY.md`;
  - built JPEG-only and without file access (`src/engine/formats/stb_image_impl.c`);
  - wrapped by `jpeg::Decode` (`src/engine/formats/jpeg.*`).
- **Now:** the intro loads both pictures through the Vfs into the support panel's `proc00`/`proc01`. The route's shot shows "Umi's fan" and "Rin's fan" as whole cards, as in the game's intro.

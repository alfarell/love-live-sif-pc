# M12 survey: photos and profile cards

Date: 2026-11-16 18:11 (Asia/Jakarta). M11 is done (the user checked its 7 items on 2026-11-16). This survey picks the next item of the roadmap's "Later breadth" list: the profile card itself, support profile cards in lives and Collection → Member Card (left open by M11). It reads the data tables, the game's texts, the layouts and an earlier shadPS4 capture. Nothing new was run in shadPS4.

**Helper:** `work/m12/profile_tables.py` decodes the two tables below from the dump in memory (nothing extracted).

**Terms:**
- **Profile card:** the player's "card": a photo, a frame, the accolade, name plate, badge, a member card, three skill cards and the Friendship level. Other players' cards support a live.
- **Support card:** a profile card that helps the player in a live. Offline, these are NPC cards.

## The key finding: profile cards need photos, and photos need the Camera

- **A new save has no profile card.** The M7 capture `work/shadps4-run/pc-02.png` (Collection → Profile Card) shows a logo placeholder under "Current Profile Card". "Create a New Profile Card" and "Everyone's Profile Cards" are greyed. Prepare's "Profile Card Selection" was greyed in M11 S2 too.
- **What the texts say:**
  - 496: "Create your very own Profile Card by combining frames, Accolades, and photos you have taken!"
  - 506: "You can save up to 30 photos and 20 Profile Cards."
  - 389 (the help line of View Live Show): "Choose a song and use the Camera function to take photos."
  - 575 "Photos taken this time:", 568/569 photo saving, 799-802 deleting photos and cards, 685 "No photo".
- **Conclusion (hypothesis until S1/S2):** "Create a New Profile Card" opens once a photo exists. Photos are taken in **View Live Show** with its Camera function. View Live Show is not built, so the chain is: View Live Show + Camera → photos (Collection → Photo Gallery) → create a profile card → use it in lives.

## Data

**`common/common.pac/card.pac/profile_card_datas.bin`, `s_profile_card_frame_datas`:** 183 records of 160 bytes.

| Offset | Content |
|---|---|
| +0x00 | frame id |
| +0x04 | 1 = owned from the start (20 frames: 1001-1022, one per member), else 0 |
| +0x08 | member (1-22) |
| +0x10 … +0x30 | 5 string pointers: the name in JP, EN, CN, TW, then a JP note |
| +0x38 … | colour words (RGB, then a 0/1 flag) for the card's texts; *hypothesis*, not decoded |

- **Ids:** 1001-1022 initial frames; 1-76 and 5001+ birthday frames (2017-2020); 6011+/7011+ group frames; 8011+ and 9021+ more birthdays.
- **The JP note of the non-initial frames:** "this frame can only be shown and chosen in <member>'s live history". How they are earned is not known (events or downloads, *hypothesis*). Only the 20 initial frames are certain offline.
- **Textures:** `ui/ui_profile_card.pac/texture.pac`, 172 `pfc_bg_NNN` and 212 `pfc_frame_*` names (`pfc_frame_000_*` and `pfc_frame_h*`).

**`card.pac/preset_profilecard.bin`, `ll3::s_preset_profilecard`:** 20 records of 96 bytes, the NPC support cards.

| Field (i32) | Content |
|---|---|
| 0 | index 0-19 |
| 1 | member card (10031, … 111051, … 222001) |
| 2-7 | empty (skill slots, *hypothesis*) |
| 8 | frame (1001-1022: the member's initial frame) |
| 9 | 120 / 1120 / 1900 (*not known*) |
| 11, 12, 13 | accolade, badge, name plate (2550 / 901001 / 19001 for µ's) |
| 14-23 | 5 string pointers: the photo file (`preset_0000.jpg`), then the player name in JP, EN, CN, TW ("Honoka's fan") |

**Photos of the presets:** `CUSA24620/proca_preset/preset_NNNN[_en|_cn|_tw].jpg`, 80 files of 672 × 1100. Each is a **whole rendered profile card** (checked `preset_0005_en.jpg`, a local PNG copy in `work/m12/`): photo, member and accolade banner, costume, badge, the player's name on the name plate, the member's name with three "Skill not set" rows and a Friendship heart with 1. So the game renders profile cards to JPEG (the eboot has libjpeg and "LP5 Profile Card JPEG by %s", `analysis/202610311616-sif-executable/`).

## Layouts (`ui2/40_collection`)

- **Profile Card menu:** `uil0090_ProcMenuLayout00`, buttons `uil0091_MenuButGroup00`. The port skips it (M7 shortcut) and opens Change Accolade or Name Plate.

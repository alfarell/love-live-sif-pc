# M13 survey: the 3D navigator, member choice, "Trying It On" and special colours

Date: 2026-11-17 21:06 (Asia/Jakarta). M12 is done (the user checked its 9 items on 2026-11-17). The user chose the first "Later breadth" item of the roadmap: member names, the 3D navigator, "Trying It On" and special costume colours. This survey reads the game's texts, the file list (`work/pac-list.csv`), earlier shadPS4 captures and the port's code. Nothing new was run in shadPS4 and nothing was extracted.

**Terms:**
- **Navigator:** the 3D member who stands in the room on the top menu and talks to the player. In this game she is also "your member": the one who plays the lives.
- **Motion:** an animation clip for a model's skeleton. **Facial motion:** a clip that moves only the face (mouth shapes, blinks, brows).
- **BTL timeline (`.btlb`):** the game's event list over time (see `repository/docs/formats/talk.md`).

## The port today

- **Top menu:** UI only (room, wheel, header). No 3D member. The navigator's voice lines play (M7), always Honoka: `src/app/top_menu.cpp:47` (`kNavigator = 1`, shortcut).
- **Played member:** `--member`, else 1 (`src/app/main.cpp:403`, same shortcut). Skill cards (M11), photos and profile cards (M12) all follow this member.
- **Costumes:** `save.wear` gives each member her own costume (M7). The costume screen and the song select's costume step show pictures, not a 3D member (`costume_screen.cpp:146`, `song_select.cpp:219`, shortcuts).
- **The 3D path exists from lives (M5):** member models with costumes, dance motions, the camera and the renderer. The navigator and "Trying It On" reuse it with another motion, one member and a fixed camera.

## Data in the dump

**Navigator motions** (`chr/c01/c01.pac/motion.pac`, Honoka; the other members have the same pattern):
- `000-002 stand`, `010-020 idle` (7 clips), `050 nod`, `060/061 rotation`, `070 surprise`, `080 anger`, `090 byebye`, `100/111 jump`, `120/121 livestart`, `130/131 choice`, `140 select`, `141 fix`.
- result reactions `030 great`, `031 AP`, `032 FC`, `033-037 SSS … B`;
- a second set `500-521`: `stand`, `idle1/2`, `talk1-4`, `login`, `announce`, `livestart1/2`, AP … B, **`518 dresschk`, `519 dressfix`** (*hypothesis:* "Trying It On" and "Change Clothes"), `520 liveend`.
- facial clips: mouth shapes `a i u e o n`, `smile`, `happy`, blinks and winks, brows.

**Timelines** (`chr/c01/c01.pac/timeline.pac`): 185 `voice_NN_honoka_NNN.btlb` and one `mot_….btlb` per motion. *Hypothesis:* the voice timelines drive the mouth (lip sync) and the motion timelines the face during a motion. The talk timelines' tags `0x0028`/`0x0443` are not decoded yet (M7).

**Special colours:** 144 costume folders have a second pac `dNNN_v1.pac` beside `dNNN.pac` (for example `chr/c01/d003/d003_v1.pac`), with the same model and texture names. The costume table's flag bit 16 marks these costumes (`docs/formats/costume.md`).

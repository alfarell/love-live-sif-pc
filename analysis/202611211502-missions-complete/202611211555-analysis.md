## Save

**Two generic line types** (`save.h`), instead of a field per mission:
- `counter KEY N`: `SaveData::counters`;
- `set KEY id id …`: `SaveData::sets`.

**Helpers:** `Count`, `Add`, `Best`, `Mark`, `Marked`, `SetSize`, `GroupKey(mode, name)` and `CountCollected(type, item, amount)`.

**The keys:**

| Key | What | Mission kinds |
|---|---|---|
| `gG.plays`, `gG.perfects`, `gG.greats`, `gG.full_combos`, `gG.best_score`, `gG.best_rank` (rank + 1) | per group, G = the played member's mode (Q2: group missions count per group) | 0-6 |
| `collected.key`, `collected.thread`, `collected.cloth` | materials gained in all | 8-10 |
| set `keys` | key items ever gained | 11 |
| `views`, `view.S` | View Live Show plays, in all and per song | 12, 36 |
| set `view_costumes` | costumes worn in a viewed live | 43 |
| `photos`, `photo.D` | photos taken, in all and per costume | 13, 45 |
| set `camera_photo` | members photographed in the Member camera | 33 |
| `camera.M` | seconds in the Member camera on member M | 26 |
| set `talk.M` | M's phrases heard (talk ids) | 21 |
| set `menu.M` | costumes M wore on the top menu | 27, 28, 42 |
| `cards.M`, set `card_costumes` | profile cards made of M, and their costumes | 24, 46 |
| set `special` | costumes played in a special colour | 48 |

## Where they are fed

**After a played live (`main.cpp`):**
- the `gG.*` totals for the played member's group;
- the costume in `special` when she wears it in its special colour.

**The drops:** `CountCollected` by item type:
- 1/2 key items;
- odd types ≥ 3 threads;
- even types ≥ 4 cloths.

**After a finished View Live Show:**
- `views` and `view.S`;
- the costume in `view_costumes`;
- the Member camera's seconds per member (`LiveResult::camera_seconds`, added in `live_screen.cpp`);
- log: `missions: View Live Show N times`.

**Photos (`CountPhotos`, before they are saved):**
- `photos`;
- `photo.D` with the played member's costume;
- `camera_photo` for each photo taken in the Member camera (`LiveResult::Photo::camera_member`).
- *Hypothesis:* "looks at the camera" (kind 33) is a photo in the Member camera on her.

**The top menu:**
- each greeting and T line → `talk.M`;
- each member shown → her costume in `menu.M`;
- the login bonus's key items → `CountCollected`.

**The birthday reward's key items** → `CountCollected`.

**Finish Editing a profile card** → `cards.M` and `card_costumes`.

**An older save** gets `gG.*` seeded once from its records (`SeedGroupCounters`):
- each song's plays, FULL COMBOs, best score and rank go to its group (Saint Snow with Aqours);
- the GREAT/PERFECT totals were kept for both groups together, so they go to the group with more plays (*shortcut*, in the code).
- Log: `missions: per-group counts seeded from the records (M15)`.

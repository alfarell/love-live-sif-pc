# analysis

Findings and notes: how pt-pc works, what the Love Live SIF dump contains, and how they compare.

## Rules

- Every new analysis topic gets its own folder: `<timestamp>-<topic>` (timestamp `YYYYMMDDHHmm`, local time Asia/Jakarta; topic in lowercase kebab-case). Example: `202610311300-analyze-game`.
- Inside it, each result is a markdown file named `<timestamp>-analysis.md`, with the timestamp of when that file was created.
- Further work on the same topic adds a new timestamped file in the same folder; earlier files are not overwritten.
- Cite file paths for every claim and mark guesses as guesses.

```
analysis/
└── 202610311300-analyze-game/
    ├── 202610311300-analysis.md
    └── 202610311422-analysis.md
```

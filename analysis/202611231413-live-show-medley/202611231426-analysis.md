## 1. The table (done)

**`FUN_000ccc80`** loads `medley_data.bin` → `DAT_00e1c9b0` (the rows) and `DAT_00e1c9b8` (the count, size / 0x120). Its helpers:
- `FUN_000ccd70`: the count;
- `FUN_000ccda0(id)`: a row by id (the first row if not found);
- `FUN_000ccde0(id)`: a row by id, or none;
- `FUN_000cce20(id)`: the number of songs (the first empty song slot).

**The fields left open by the survey:**

| Offset | Meaning |
|---|---|
| +0x2c | **The Set List's stage** (one stage for the whole list): `G+0x464f6c`, then `G+0x464e14` (the stage the live loads). The values 1-19 and 101-112 are the stage folders `st001`-`st019` and `st101`-`st112`. |
| +0xd0 | **The special colour of each entry** (byte): `G+0x464e34`. The live wears colour 0 if the costume has fewer colours (`FUN_000b7d30`: `+0x5a` of the costume row). |

## 2. The medley being played (done)

**`FUN_00185ee0`** (Prepare → start, mode `+0x22c` = 3) fills the medley at `G+0x464e20`:

| `G+` | Content |
|---|---|
| `0x464e20` | 1 = a recommended list, 0 = your own |
| `0x464e24` | the list: the id of a recommended list, or the slot of your own (0-9) |
| `0x464e28` | 20 entries of 16 bytes. Each has: the chart (song × 1000 + the difficulty variant; variants 5+ are stored +5, as in Play), the member, the member card (the costume), and the special colour (byte) |
| `0x464f68` | the number of entries (the last filled one + 1) |
| `0x464f6c` | the stage |
| `0x464f70` | the list's name (your own lists) |
| `0x464fb4 + i × 8` | per entry: `+0` skip (the song is missing, or locked by its add-on: `FUN_001efa70`), `+1` the costume is locked (`FUN_001efc40`), `+4` watched this time (int) |

**A recommended list:**
- **The member of each entry** is the current member if the costume has a card for her. Otherwise it is the song's centre member: the middle of its member list.
  - The card is looked up as `FUN_00010830(member, costume, 2)`, then `…, 1)`.
- **A locked costume** (no add-on) is replaced by the default card (`FUN_00010e50`) with colour 0 (`FUN_0008f1d0`).

**Your own lists** are kept in the save at `S + 0x531d8 + group × 0xf7c + slot × 0x18c`:
- **10 lists per group** (µ's, Aqours); 0x18c bytes is exactly `G+0x464e28` to `G+0x464fb4`.
- **The name:** an empty name shows "Original Set List%d" (626) with the slot + 1.
- **The stage:** a list with no stage gets 1 for µ's or 102 (0x66) for Aqours.
- The name is typed in the PS4's IME dialog (`libSceImeDialog`, string "ImeDialog"). Message 627 asks for 16 characters.

## 3. The live (done, in outline)

The live object has the mode at `+0x90`: 1 = medley, 3 = View Live Show. **`FUN_0008f890`** is the live's state loop.

- **Start** (`FUN_0008f1d0`): the first entry that is not skipped. The stage is the list's, for the whole medley; the members, costume and colour are the entry's.
- **Preload** (`FUN_000b7d30`): while a song plays, the next entry's costumes and members are loaded for all 11 member slots. The change happens on the same stage without leaving the live.
- **State 10, the song's end:** in a medley, state 11 (`FUN_000bab10`) shows the title of the next song for **300 frames (5 s)**. *Hypothesis:* this is `uil0004_MedleyMode00` with `medley_title_T_<song>`, `ui_medley_title_back00/01_<group>` and `ef_655_medley_title00`; R2 checks it.
- **State 14, a song done:** in a medley:
  - the song's medley count goes up, in the song records `G+0x959bc`;
  - the entry is marked watched (`G+0x464fb8`);
  - the seconds watched are added to `G+0x8efb8` (the debug string "MedlayPlayTime: (minute)");
  - the next entry that is not skipped loads (state 3). After the last one, the end comes (state 15).
- **The end:** `G+0x464e1c` chooses the result (state 19) or a direct exit (state 23).
  - **The result:** `FUN_00157af0` shows the list as "%02d.%s / %s" (number, song title, costume). It shows the list's name (the recommended name, or yours, or "Original Set List%d").
  - **The choices:** "Watch the Same Medley List" (570) and "Return to Medley Selection" (571).
  - *Hypothesis:* `result_medley00` is this screen's help key.
- **The interval camera:** `s_medleyIntervalCameraAnimParams` (24-byte rows in `stage_common.pac/stage_params.bin`, `FUN_0023b590`; read by `FUN_0023ba00(i)`) is the camera between songs. Its caller was not found by a direct call (a virtual call). *Hypothesis:* it moves during the 5-second title.

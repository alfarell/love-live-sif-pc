## The port

### `app/popup.{h,cpp}`
`Popup` is the common box:
- `OpenMessage(title, text, buttons, focus)` or `OpenChoices(title, rows)`;
- arrows move, Space / Enter choose, Esc cancels;
- it is drawn at the centre by the new `UiScreen::DrawLayout(…, x, y)`.

The rows are drawn in the message's font, left-aligned, with the focused one orange, using the new `UiScreen::SetInstanceTextStyle`. *Shortcut:* the colour is read off shadPS4's picture.

### The medley end screen
OPTIONS (Enter) now opens "What will you do next?" (570, 571, 566), as in shadPS4 `e1`. Cross (Space, "End") returns to the Set List screen. *Hypothesis:* not tried in shadPS4.

### `app/medley_screen.{h,cpp}`: `RunMedleySelect`

**Set List Selection:**
- ↕ chooses a list; L1/R1 switch the tab; L2 toggles the group (`save.mode`).
- □ renames your list. **Rename uses the PC keyboard** (SDL text input, 16 characters, Backspace, Enter keeps, Esc cancels); the game uses the PS4 IME.
- ✕ edits your list.
- touchpad (Enter) asks "Confirmation of medley start" (Back / OK, Back focused, as in `b3`). A list with no usable song gets the "cannot start" message instead.
- ○ returns to the top menu.
- The tab and list are kept between visits (`MedleyPlace`).

**Set list editing:**
- ↕ moves the line cursor;
- R1 Clear, R2 Insert (the last slot drops off), L2 Delete (the slots below move up);
- □ Change Stage, ✕ Modify (Edit Slot NN);
- touchpad Finish Editing writes the list to the save;
- ○ Cancel asks "Discard edits and return to list?" (Cancel / OK) when something changed.

**The Edit Slot panel:**
- the Songs and Costumes rows, with the song cover or costume picture and the name;
- ↕ picks the row; **Left / Right step through the choices**; OK (Space / Enter) sets the slot.

*Shortcut:* the game picks from the card strip (`uil0013_MusicList00`, "1/23 Sets", L1/R1 pages), which is hidden here.

**What is offered:**
- the group's songs (Saint Snow's with Aqours) and costumes by id (0-99 µ's, 100+ Aqours), owned ones only (add-ons, `costume::Owns`);
- a new slot gets the first costume, as the game prefills one.

*Shortcut:* the rule for which costumes a song can wear (640) is not traced.

**Not built:**
- "Change to special color";
- R2 Switch Members on this screen;
- the help bar's button hints (no screen in the port fills them).

### The flow (`main.cpp`)
Play → Live Show Medley:
1. Set List Selection;
2. the medley;
3. its end, then:
   - Watch the Same Medley List plays again;
   - Return to Medley Selection goes back to the Set List screen;
   - Return to Main Menu goes to the top menu.

The save is written after the Set List screen (lists, names, group) and after a finished medley (the counters). The R4 shortcut `--medley` is removed.

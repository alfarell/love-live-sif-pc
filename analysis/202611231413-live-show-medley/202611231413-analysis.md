# M16 survey: Live Show Medley

Date: 2026-11-23 14:13 (Asia/Jakarta). M15 is done (the user checked its 7 items on 2026-11-23). The user chose Live Show Medley for M16. This survey reads the dump's file list (`work/pac-list.csv`), the eboot strings, the messages and the medley table. Nothing new was run in shadPS4.

## What Medley is

Medley is a **viewing** mode, not a played one.
- You choose a **Set List**, and its songs play one after another as View Live Show does: no notes, no score.
- The messages say so: "Select a Set List and view the Live Shows in it.", "Watch the Same Medley List", "Return to Medley Selection".
- The mission texts say "Watch" too (`work/m13/kinds.py`):
  - kind 37: "Watch a Live Show Medley that includes [p1]";
  - kind 47: "with the [p1] set";
  - kinds 14 and 15: "Played Live Show Medleys for a total of [p2] minutes / hours".

The Medley menu has three entries (messages 412-414):
1. **Recommended Set Lists** ("おススメ！"). These cannot be edited (message 625).
2. **Your own Set Lists**: "Create your own personal Set List" (messages 415-420, 626-628).
   - Each entry has a song, a costume and a stage.
   - The list has a name of up to 16 characters; the default is "Original Set List%d".
3. **Others' Set Lists**: online, out of scope.

## The data

**`common/common.pac/medley.pac/medley_data.bin`** (BLBN) holds `ll3::medley::s_medley_datas`: 20 rows of 288 bytes. Read by `work/m16/medley_rows.py`, with the output in `work/m16/medley_rows.txt`.

| Offset | Field |
|---|---|
| +0x00 | id 1-20 |
| +0x08 | 4 string offsets: the name in jp, en, cn, tw |
| +0x28 | group: 0 µ's (ids 1-10), 1 Aqours (ids 11-20) |
| +0x2c | *Hypothesis:* the stage, or the title picture (values 1-19 and 101-112) |
| +0x30 | 20 song ids (0 = empty); 4-20 songs per list |
| +0x80 | 20 costume ids, one per song (-1 = empty) |
| +0xd0 | 20 small numbers, mostly 0, some 1-5. *Hypothesis:* the special colour, or the costume's variant |

Examples of rows:
- 1 "Wai-Wai! Live": songs 120, 340, 670, 130, all in costume 3;
- 2 "µ's for the First Time": 20 songs;
- 11 "Wai-Wai! Live" (Aqours): 4 songs, costume 105.

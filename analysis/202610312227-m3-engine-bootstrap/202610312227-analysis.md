# M3: engine bootstrap

Created: 202610312227 (Asia/Jakarta). Plan: `plan/202610311831-sif-port-roadmap/202610311831-plan.md`, milestone M3 (scope updated at CP1, `plan/202610311813-port-approach-decision/202610312057-plan.md`).

## 1. User decisions this milestone

- **Renderer base: SDL3 GPU API**, instead of copying pt-pc's `gpu`/`vk`. pt-pc's `vk_context.cpp` (1,410 lines) is tied to DLSS/Streamline, HDR and driver workarounds; SIF needs about 9 shaders. SDL GPU is already linked, gives Vulkan (and later D3D12) backends, BC1/BC3/BC7 textures and vsync/mailbox/immediate present modes.

Downloads made without a separate question (small source files, public domain, same pattern as clHCA): the LZMA SDK decoder files and two vgmstream ADX files kept as reference in `work/ref/` (not copied; the ADX decoder was written from the format).

## 3. Findings

- **Latency:** SDL/WASAPI (shared mode) granted 480 frames (10 ms) when 256 were requested; that is the shared-mode device period. End-to-end latency (buffer + mixer + driver + hardware) is not measured yet; M4's calibration screen covers the rest.
- **Clock basis:** audio is consumed at exactly real-time pace (fed frames = wall time × 48,000). Fed frames minus the device buffer is a usable song-position clock for M4 (to be validated against a recording).
- **Cue names are titles:** music cue names are song titles (e.g. `僕らのLIVE君とのLIFE`). Song-ID → cue mapping must come from the game tables (`live/<id>/data.pac` or master tables), not from file names.
- **`sys.acb`'s `StreamAwbHash` is a 16-byte blob**, not a table (no stream banks); handled.

## 4. Open questions

1. Listening check by the user: `sif.exe` plays song 0010 by default; `--play sys:11_gatya` plays an ADX sound. Statistics pass, but a human ear is the real test (also for the M2 WAVs in `work/audio/`).
2. Exclusive-mode / lower latency: is 10 ms shared mode good enough? Decide after M4 timing tests.
3. Song-ID → music cue mapping (see Findings).
4. Release build not tested this milestone (debug only).
5. D3D12 backend: needs DXIL shaders (SDL_shadercross or dxc). Not needed while Vulkan works.

## 5. Plan changes needed

- Roadmap M3 "Renderer core (pt-pc `gpu`/`vk`)" becomes "Renderer core (SDL3 GPU API)" by user decision; pt-pc's renderer stays a reference for later features (bindless, pipeline cache).
- M4 inherits: master clock from fed frames minus device buffer, calibration of the remaining latency, and the song-ID → cue mapping.
- Decoding a whole song takes about 0.5 s in a debug build. Fine for M4; streaming decode later if load time matters.

## 2. Findings

| Item | Result | How checked |
|---|---|---|
| Motion key | 12 bytes: f32 frame, u32 byte offset into the value array, u32 interpolation flag | Offsets run 0, 12, 24, … (translate/scale) and 0, 16, 32, … (rotate); frames increase in all 319 animation files |
| Channel types | 0 translate (f32[3]), 3 rotate (quaternion x, y, z, w), 2 scale (f32[3]) | Value strides 12/16/12; scale keys are 1.0 |
| Quaternion order | x, y, z, w; same rotation as the `NODE` Euler angles (T · Rz · Ry · Rx · S) | Frame-0 keys equal the bind rotation for the 27 nodes that don't move at frame 0; w-first order matches none |
| Dance timing | 60 fps, 9,060 frames (151 s), keys every 2 frames | `ANHD`, key frames 0, 536, 538, … |
| Skin palette `MTXP` | u32 node indices + column-major inverse bind matrices (Z-up model space) | world(node) × inverse bind = identity, error 0 on 4 entries |
| Skin attribute | **8 influences**: two sets of (f32×4 weights, u8×4 bones); the second set was misread as "20 bytes zero" in M2 | The 8 weights sum to 1 on a hair vertex. With 4 influences, hair vertices collapse into spikes; with 8, the pose is clean |

**Visual check:** `bmar_dump.py mod_01_honoka.mdl --motion mot_01_honoka_0010_borarara.mot --frame N --preview` at frames 0, 1800, 3600 and 6000 gives clean dance poses (arms raised, stepping, hands together), with no stretched triangles. The preview PNGs are in `work/m5/`, not committed.

## 3. Tool changes

`repository/tools/bmar_dump.py` gained:
- `parse_motion` and `sample` (linear interpolation, normalized lerp for quaternions);
- `pose`, and the `MTXP` palette;
- skinning in `geometry` (8 influences), only when posed;
- the `--motion`/`--frame` options.

Its output for the bind pose is unchanged.

## 4. Open

1. Interpolation flags 1 and 2 (10 channels across 319 files, values of 36 bytes with flag 2): read as linear for now.
2. `mod_01_honoka` is the base body; the costume models are other files in `chr/c01/c01.pac`. The live costume choice is not traced.
3. Hair and skirt bones (`c01_hnk_bon_hair*`) have no motion tracks. They follow their parents; physics (`dynamics.pac`, `BMD`) comes later.
4. `ANMS`/`ANMT` tracks: not decoded (*Hypothesis:* facial morph and material animation).

## 3. Render cost (CP2 switch signal 2)

`sif.exe --live 10:4 --autoplay --frames 4000`, Vulkan, vsync. The stage (66 meshes) plus 9 members, CPU-skinned every frame (8 influences) and uploaded:

| Build | CPU per frame, mean | Median | 99th percentile |
|---|---|---|---|
| Debug | 15.15 ms | 15.00 ms | 17.51 ms |
| Release (`RelWithDebInfo`, `work/build/release`) | **3.78 ms** | 3.72 ms | 4.83 ms |

The Release build uses under a quarter of a 60 fps frame (16.7 ms), so the **switch signal "shader/render needs dwarf the budget" is not triggered**.

Limits of this measurement:
- GPU time is not measured separately; vsync hides it. The run showed no dropped frames: 4,000 frames in about 22 s at the display's refresh rate.
- The renderer still draws only one material type (one light, alpha test).
- The game's 9 shader materials, transparency, effects and costumes will add cost.

The Release build reuses the Debug folder's SDL and zlib sources (`FETCHCONTENT_SOURCE_DIR_*`); nothing was downloaded.

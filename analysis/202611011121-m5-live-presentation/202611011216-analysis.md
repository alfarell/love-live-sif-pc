## 2. What was built

| Part | File | Notes |
|---|---|---|
| Math | `src/engine/core/math.h` | Column-major Mat4, Euler (Rz·Ry·Rx) and quaternion rotations, perspective (depth 0..1), look-at |
| BMAR reader | `src/engine/formats/bmar.{h,cpp}` | Nodes, meshes (vertex layout from the format bits), draws, materials, `MTXP` palette, embedded `BMT` textures; motions; `Pose` (linear keys, nlerp). Bounds-checked reads |
| Renderer | `src/engine/render/renderer.{h,cpp}`, `shaders/mesh.{vert,frag}` | Depth buffer (D32F, else D16), textured mesh pipeline (alpha test 0.5, one fixed light, no culling), repeat sampler, white fallback texture. | Scene model | `src/engine/render/scene_model.{h,cpp}` | One GPU mesh per `DRAW`; textures from `BMT`, then `texture.texs`/`texture.pac` next to the model or next to its `model.pac`; CPU skinning with 8 influences, uploaded every frame |
| Live screen | `src/app/live_screen.cpp`, `main.cpp` | `--stage stNNN` (default `st017`), `--member N` (default 1); dance frame = audio time × 60 fps; fixed camera at (0, −6, 1.4) looking at (0, 0, 1) in the Z-up world |

## 3. Build note

The first reconfigure was started from the Bash tool, where `w64devkit\bin` is on PATH. CMake then cached w64devkit's `ld.exe` and `ar.exe` as linker and librarian, and the configure failed. A fresh configure (`cmake --preset debug --fresh`) inside `vcvars64.bat`, with w64devkit removed from PATH for that shell only, gives `llvm-lib`/`lld-link` again. The user's PATH was not changed.

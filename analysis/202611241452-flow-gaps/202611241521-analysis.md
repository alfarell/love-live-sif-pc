## 1. "You cannot play … with this member" (591): traced

**Where:** `FUN_00173b60`, the song select's state machine, state 2 (a song was chosen).

**The rule:**
- It reads the song's row (`FUN_00094660`, `s_music_datas`) and the current member (`FUN_00119b70`).
- If the member is in the song's singer list (`+0x18` count, `+0x1C` ids), the song goes on (`LAB_00174435`).
- Otherwise it opens a Yes / No box with message 591. The two `%s` are the member's name and the song title. The Japanese text has the member first; the English text has only the song.
- **The exception:** song 1380 ("Awaken the power", Aqours with Saint Snow, 11 singers) skips the check when `FUN_000730a0` is not 0.
  - `FUN_000730a0` returns the group mode: `G+0x8f768`, or the temporary member's group when `G+0x46507C` is set.
  - So in Aqours mode, 1380 never asks.
  - *Hypothesis:* in µ's mode it asks as any other song does.
- **The check covers solo and sub-unit songs.** Examples:
  - 480 "Kodoku na Heaven": Hanayo (8) only;
  - 1070-1170: Aqours sub-units of 3;
  - 1220-1240: duos;
  - 1470-: Aqours solos.

**The answer** (state 3):
- **Yes:** a member choice box (`FUN_0025d8d0`) listing only the song's singers.
- **The choice** (state 4): the picked member (`FUN_0025ecb0`) gets the **member loading screen** `com_load_mem00_%02d` (`FUN_00263570`, the "_charaTex_splash00" picture; the same call is used by the R2 member change). The temporary member is then set.
- **No:** back to the song select.

**When the temporary member ends:** not traced. *Hypothesis:* on the return to the top menu (T2 checks this).

**The port today:** `SongInfo::members` already holds the singer list (`song.cpp`, `+0x18` / `+0x1C`). The member popup exists (`app/member_popup`, M13 N5).

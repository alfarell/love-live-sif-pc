# T4: "What will you do next?" after a live (implemented)

Date: 2026-11-24 18:14 (Asia/Jakarta). Step T4 of `plan/202611241452-m17-flow-gaps/202611241452-plan.md`. Follows T3 (`202611241723-analysis.md`).

## What the port does now

**The box** (`app/result_screen.cpp`, `WhatNext`) is the M16 common popup's four-row form:
- the title is row 1 of the title atlas;
- the rows are **Close the Window** (574), **Play Live Show Again** (564), **Return to Song Selection** (565) and **Return to Main Menu** (566);
- the arrow starts on the first row, as in M12 `v19`.

**Where it opens:**
- **Play Live Show:** on the key that used to end the result, after the Items Obtained page.
- **View Live Show:** on Enter or Space on End the Live Show. The photos are saved after the box.

**The choices** (`main.cpp`):

| Choice | What happens |
|---|---|
| Close the Window, or Esc | The box closes and the result or End screen stays. The next key opens the box again |
| Play Live Show Again | The same song, difficulty, stage and costume start at once, without the song select. A played live still shows its intro |
| Return to Song Selection | The song select, as before M17 |
| Return to Main Menu | The top menu |

**A changed rule:** a finished View Live Show no longer shows the judged result screen. The game ends a viewed live with End the Live Show, and the port's own comment already said a viewed live has no result.

## Routes

- **`what_next`** (new):
  - a played live, then the box (shot `what_next`);
  - Close the Window, then a key opens the box again;
  - Play Live Show Again: the second play is counted, and the song select is visited only once;
  - after it, Up from the first row wraps to Return to Main Menu, and the top menu comes back.
- **`career_1_play`, `boosters`, `live_view`:** these now pass the box with Return to Song Selection.

## Shortcuts and hypotheses

- **The key that reopens the box** after Close the Window is not seen in shadPS4. In the port, any key reopens it. *Hypothesis:* the game uses OPTIONS, as on the medley end screen.
- **Play Live Show Again:**
  - skips Prepare, so a Wai-Wai! Booster is not used again;
  - the game's own path for it (whether it shows Prepare) is not traced.
- **View Live Show without photos:**
  - the port skips End the Live Show and the box, and goes back to the song select (as before);
  - in the game, whether End the Live Show shows without photos is not seen.
- **The background:** the game blurs the screen behind the box (`v19`); the port draws it sharp, as the M16 popups do.
- **Not shown before the box:**
  - "This stage has been unlocked!" notices;
  - the ranking prompt, which is online and out of scope.

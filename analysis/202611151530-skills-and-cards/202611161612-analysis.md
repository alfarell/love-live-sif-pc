## Member cards in Select Costume

**The game** (shadPS4 S2 `s12`): Select Costume is its own layout, `ui2/20_setup` `uil0025_CosSelect00`, which the step layout places but the port never drew.
- **Top left:** the costume's picture and name, with parts borrowed from `30_costume`: `ctg30_uip0007_CosPreview00` and `ctg30_uip0003_CosName00`.
- **Info panel** (`ctg30_uip0006_CosInfo00`): one picture per costume. It holds the effect line, the "Costumes for Nine" label and the members' chibis.
- **Description:** `common_uip0009_SelectInfoWin00`.
- **Right:** the played member's member card, large (`uip0047_CharaCard00`).
- **Plates:** each costume plate (`uip0045_CosSelect00`) shows the played member's card in that costume (`card_center00`).
- **List counter:** "N/M Sets" (`uip0049_CosNumber00`).

**Which picture:**
- **Path:** `ui/ui_member_card_thumbnail.pac/texture.pac/mbc_<card id>`.
- **Card id:** (member × 1000 + costume) × 10 + p, with the costume at `s_member_card_datas +0x14`. Per S6b, that field is the costume id the game wears.
- **p:** p = 0 is the R picture and p = 1 the HR picture of the same costume (`mbc_10010` R, `mbc_10011` HR, decoded). The HR is *likely* the "special colour" version (L2 "Change to special color" in `s12`).
- **Shown:** the game shows the R card in Select Costume, so the port uses p = 0.

**The info picture:** `ui/ui_dress_info_popup[_en|_cn|_tw].pac/texture.pac/cos_pop_info_<costume %04d>_T`. The part's own `cos_pop_info_0000` is a Japanese placeholder ("効果: ここに衣装効果の説明が入ります", "9人衣装").

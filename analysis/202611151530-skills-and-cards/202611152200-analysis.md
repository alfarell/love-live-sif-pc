## Which note is the skill note (eboot, new in S5)

Ghidra decompiles of `FUN_00099280`, `FUN_00099620`, `FUN_000ca580` and `FUN_00099080`. The `.c` files are in the session scratchpad and not committed.

**Chart setup** (`FUN_000a1df0`):
- **Phases:** each icon channel (2-4) maps to one phase. `FUN_000ca580` gives the three phase ids. `FUN_00099080`/`FUN_000990b0` give the phase's start and end. Only notes inside that time range count.
- **Slots:** the phase's kind (`FUN_00099620`, table `0x5e8084`) picks the slot and its flag (`0x10`/`0x20`/`0x40`).
- **Skill note:** when that slot holds a card, a note becomes a skill note if `FUN_00099280(note)` equals the player's index (`player +0xe0`).
  - It gets the slot flag, the timed flag (when the level's seconds > 0) and the icon flag `0x400`. **So a skill note is still a Rhythm Icon note.**
  - Every other note in range takes the next entry of the Rhythm Icon bag.
- **`FUN_00099280`** searches nine note lists (stride `0x48`, up to 8 notes each) for the note. It returns the note's **position** in its list.
  - So the note "belongs" to the player whose index equals that position: 0 for the played member, 1-2 for the support players.

*Shortcut* in `MarkSkillNotes` (`chart.h`):
- The port does not rebuild the nine lists. It makes **the first icon note of the slot's phase** the skill note, one per set slot.
- This fits the bag size: 9 minus the number of set cards (`FUN_000a0d80`, S1).
- **Not checked:** which icon note of the phase the game picks. No reference capture exists (S2 saw no skill note).

|---|---|---|
| 0 Judge Plus, 1 Combo Support, 13 Judge Support, 15 Long Notes Support, 38 Judge Support + | 5 → 14 s | timed, fired by the skill note |

## Change

**`src/game/live/judge.h/.cpp`:**
- **`WindowSet`:** gains `press_wide` and `release_wide`, read from `s_EvaluateRangeDatas` groups 2-3. The real table gives the same bounds +20 ms (60/153/220/287 and 153/220/287/353).
- **`Skill`:** slot, card, kind, duration in ms, amount. **`Judge::Reset(…, skills)`** arms the untimed ones.
- **`SkillLog()`:** every firing and every use. **`SkillActive(kind, t)`:** whether a skill is in effect at time t.
- **The effects:**
  - **firing:** a skill note hit better than Miss starts its slot's timed skill for `seconds × 1000` ms from the hit;
  - **Judge Support, Judge Support +, Starting Combo Support:** the wide windows, for presses and releases;
  - **Judge Plus:** Great → Perfect, Good → Great;
  - **Combo Support, Judge Support +:** a Good keeps the combo;
  - **Starting Combo Support:** each combo break uses one of its amount;
  - **Finale Support:** a missed icon note still counts toward the finale (`icons`), one use each;
  - **Long Notes Support:** a hold pressed while it is active ignores the release and ends **Perfect** at its end. The remaining ticks are awarded as for a Perfect release.
- **Refactor:** a hold's end (release, miss, automatic) goes through one function, `EndHold`.

**`src/game/live/chart.h/.cpp`:** `Note::skill` (slot or −1) and `MarkSkillNotes`.

**`src/app/skill_screen.h/.cpp`:**
- **`LiveSkills(setup)`:** the played member's three slots at their owned levels, in full strength (no support share).
- **`SkillPlateV`:** now public. The in-game banner uses the same plate rows.

**`src/app/live_screen.cpp`:**
- **Skill notes:** marked before the judge starts.
- **Log lines:**
  - `live: skill slot 1: card 11000 kind 13, 7000 ms, skill note at 34285 ms`;
  - `live: skill fired: slot 1 card 11000 kind 13 at 34285 ms, until 41285 ms`.
- **Skill banner:** `ui2/90_ingame` `uil0005_ActiveSkillLayout00`, drawn over the HUD.
  - **Placement:** the top four of its six `uip0018_ActiveSkill00` instances, one per skill in effect.
  - **Plate:** `ui_ingame_skill_frame00`, row by the card's series.
  - **Name:** `ui_ingame_skill_text00_T`, 4 × 10 cells of 320 × 48 px. The kind → cell map is read from the decoded atlas (English and Japanese have the same order).

**`src/app/main.cpp`:** the select's live gets `LiveSkills(skills)`, in both modes. S1 found no mode check.

## Shortcuts (in code comments)

- **Skill note choice:** the first icon note of the phase (see above).
- **Untimed banners:** an untimed skill's use shows for 2 s. The game's time is not traced.
- **Voice:** the firing voice (`eVoice_invokeSkillMain`) is chosen in code, not in a table, and is not traced. `s_skillVoiceCues` (`live_params.bin`) has 20 rows × 30 cue ids (e.g. 10020…). Those rows go with `s_skillVoiceCallNum` = 30, so they are Shoutout's voice calls.
- **Shoutout:** no effect, since its timing is not traced.
- **Skill effects:** the 3D effects (`effect/ef.pac` `ef_842/843_skill_effect*`), Member Focus's camera and Effect Shower/Frame are not drawn.
- **Skill note look:** skill notes look like icon notes. The eboot's `skill_icon%02d_%02d` texture was not found in the UI packages.
- **Support players:** skills from support profile cards (half duration, `share` %) are left out. The offline NPC presets set no cards (S2).

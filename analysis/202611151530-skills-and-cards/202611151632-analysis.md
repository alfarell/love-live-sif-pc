# S2: skill cards in a shadPS4 run

Date: 2026-11-15 16:32 (Asia/Jakarta). Step S2 of `plan/202611151530-m11-skills-and-cards/202611151530-plan.md`. Follows S1 (`202611151548-analysis.md`).

## Method

- **Emulator and save:** shadPS4 (`work/shadps4-build`), run from `work/shadps4-run` with its own `user/` folder. The game's save carries over from the M10 run. Nothing under `%APPDATA%\shadPS4` changed (checked after closing).
- **Driving it:** `work/scripts/shadpost.ps1` with a new wrapper `work/m11/go.sh NAME KEY... wMS`, which presses keys and takes one shot. Keys go only to the shadPS4 window, and shots are only of that window.
- **Pictures:** `work/m11/shad/s01.png` … `s32.png`. Not committed.
- **Rendering:** shadPS4 draws the 3D members as black silhouettes, as in earlier runs. The UI and 2D card pictures are correct.
- **Ranking:** the game asked twice whether to resend ranking data. The answer was **No** both times; nothing went online.

## What the game shows

**Collection → Skill Card** (`s07`, `s08`):
- **Tabs:** one per member, the group's 9. L1/R1 change the member, L2 toggles µ's/Aqours.
- **Grid:** five columns of cards; unowned cards show the logo card back.
- **Skill Info panel:** the big card picture, the skill id (`S-10144`), the name, the description, "[Automatic activation]" for untimed skills, and `Lv.`.
- **Bottom line:** shows the focused card's name, with "(Not possessed)" before unowned ones.
- **Owned at the start:** one card, Honoka "Converting Threads" Lv.1 (from the M10 lives).

**Play Live Show flow** (`s11`-`s13`):
- **Steps:** Select Song → difficulty → Select Stage → Select Costume → **Prepare for the Live Show**.
- **Select Costume** shows the **member card** of the chosen costume: "R" frame, Honoka, School Unity. So member cards are the costume pictures, as the survey's hypothesis said.

**Prepare for the Live Show** (`s13`, `s18`): the screen M10 left out.
- **Left side:**
  - "Profile Card in Use" (two frames);
  - "Skill Card in Use": three rows, "Skill not set." or the card's name and `Lv.`;
  - "Receive Everyone's Profile Cards".
- **Buttons:** Game Settings, Profile Card Selection (greyed), Skill Card Selection, LIVE START (Options).
- **Right column:** the chosen song, difficulty, stage and costume; "Wai-Wai! Booster: You Have 3"; the Material Information panel.
- **Keys:** R1 Receive Profile Card ON/OFF, □ Use Wai-Wai! Booster, ✕ OK, ○ Back.

**Skill Card Selection** (`s14`-`s17`, `s32`):
- **Layout:** the owned-card list on top; "Skill Card in Use" with three slots, "R1 Remove" and OK at the bottom; the Skill Info panel on the right.
- **Setting a card:** ✕ on a slot moves the focus to the list; ✕ on a card puts it in that slot; the list then marks it with a star. OK returns to Prepare, which shows the card in the first row.
- **Only the played member's cards.** After two lives we owned cards of Honoka, Umi and Kotori, but the list showed only Honoka's (`s32`). Honoka is the member being played, and R2 "Switch Members" changes it in the menus.
- **Set cards are kept:** the slot set before the first live was still there at the next visit. This confirms S1's **three slots per member** (save `+0x8fd7c + member × 0xdc`).

**Live intro** (`s26`, after "Play Live Show Again"):
- **The player's card:** the member card (R Honoka, School Unity) and the three set skill cards (Converting Threads Lv.1 and two empty card backs).
- **"Profile Card Support":** two "(NPC Profile Card)" entries (Nico, Maki), each with three "Skill not set." rows.

**Results** (`s21`-`s31`):
- **Items Obtained:** "Friendship Points Obtained" and a level bar, Items Obtained (a skill-card icon, once also a badge), Materials Obtained, and the dropped **Skill Card** with "member, Skill, Level".
- **Two no-input lives,** each rank D with MISS 263, gave one card each:
  - Umi "Lucky Thread Support" Lv.1;
  - Kotori "Getting Skills Charge" Lv.1.
- **Close:** "This stage has been unlocked!" notices, the ranking prompt, then "What will you do next?" with Close the Window, Play Live Show Again, Return to Song Selection and Return to Main Menu.

## Answers to S1's open points

| S1 open point | Answer |
|---|---|
| Who the other "players" are | **Correction:** not the other members on stage. They are the **support profile cards** ("Profile Card Support", NPC profile cards when offline; `ll3::s_preset_profilecard`, 20 records of 96 bytes: index, member card id such as 10031, then slots that are empty in the presets). Their skill cards work at the level row's share (+0x08), and their timed skills last half as long |
| Where the focused member is chosen | The **played member**: the member whose costume is worn, switched with R2 in the menus. The live takes that member's three slots |
| Where the slots are edited | Prepare for the Live Show → Skill Card Selection, inside Play Live Show. Collection → Skill Card only views the cards |
| The `+0xc87` condition of the second draw | **S rank or better:** Kotori's card text says "A higher chance of getting more Skill Cards when they drop after achieving S or higher in a Live Show" (rank 4 = S) |
| One draw per live | Confirmed: a D-rank no-input live drops one card |
| Skills in Play Live Show (AC) | Not checked in this run. The game's texts name only Play Live Show; the Prepare screen was seen only in the home flow |
| Skill notes and effects in the live | **Not seen.** We own no live skill card (series 1), and a skill fires only when its note is hit, which the input route cannot time. Left for the port's own capture against the eboot's rules |

## Effect on the plan

- **S3:**
  - The save needs the owned list (id, level) and **three slots per member**.
  - The live uses the played member's slots (`settings`/save: the port plays Honoka unless the user switches).
  - NPC support cards: the presets have no skill cards set, so offline support adds nothing. *Shortcut candidate:* leave support players out.
- **S4:** two screens:
  - Collection → Skill Card (member tabs, grid, Skill Info);
  - the **Prepare for the Live Show** screen with Skill Card Selection.

  Prepare is new to the port (M10 left it out), so S4 grows: it adds a step between the costume and the live.
- **S5:** skill notes and the firing visuals have no reference picture. They follow the eboot (the `skill_icon` and `skill_effect00`-`02` parts) and are marked as unverified looks.
- **S6:** the drop panel is part of the result's Items Obtained screen. The port's result already shows materials, so the card is added there.

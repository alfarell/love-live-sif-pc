# S3: card data and save

Date: 2026-11-15 16:50 (Asia/Jakarta). Step S3 of `plan/202611151530-m11-skills-and-cards/202611151530-plan.md`. Follows S2 (`202611151632-analysis.md`).

## Change

**`src/game/card/card.h/.cpp` (new):**
- **`card::Load` reads three tables:**
  - `s_skill_card_datas`, the 415 skill cards: id, skill number, member, effect kind, names and descriptions in 4 languages, picture name, maximum level, the never-drop flag, and the 10 level rows (duration, amount, support share, alternative amount, level text in 4 languages);
  - `s_member_card_datas`: 1,038 member cards;
  - `ll3::reward::s_reward_datas` pool 0: the 285 skill cards a live can drop.
- **`card::Kind`** names the effect kinds that have cards, with the eboot's meaning in a comment.
- **`SkillCard::At(level)`:** the level row, clamped to 1..max. **`Timed()`** is true when the level-1 duration is above 0.
- **Owned cards:**
  - `Level(data, save, id)` = min(copies, maximum level); 0 = not owned. This is the game's rule (S1: the first copy is level 1, each further copy +1, capped at the maximum).
  - `AddSkill` adds a copy and returns the new level.
  - `OwnedSkills(member)` lists a member's owned cards. `Slots(member)` returns the member's three set cards; a card that is not owned or belongs to another member reads as empty.

**Save (`save.txt`):**
- **Copies:** stored in the existing `own 1 <card id> <copies>` lines. Task rewards already add to `owned`, so **claiming a type-1 task now gives the skill card**, with no change in the task screen.
- **Slots:** a new `skills <member> <card> <card> <card>` line, `SaveData::skill_slots`. An older port version keeps the line as an unknown line and writes it back unchanged.
- **Simpler than the game's save:** the game keeps a level per owned card (save `+0x466c`); the port keeps the copy count. The level follows from the count, so no level field is needed.

**Docs:**
- **`docs/formats/card.md` (new):** the three tables, the level row, the effect kinds, the NPC profile cards and both saves.
- **Reward type 1 is no longer a hypothesis** in `mission.h`, `save.h` and `docs/formats/mission.md`.

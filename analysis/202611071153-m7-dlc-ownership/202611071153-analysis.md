# M7: add-on (DLC) ownership and the song list

## 1. Findings

Format notes are in `repository/docs/formats/dlc.md`.

- **The user's add-ons** (`D:\Games\PS4\Love Live School Idol Festival\DLC`, 180 `.pkg` files, and `Extracted`, 180 folders) are 117 song add-ons and 63 costume add-ons.
- **An add-on has no data.** Each extracted add-on holds only `sce_sys` (param.sfo, license files, icon), so the content is in the base dump and an add-on is a licence key for it.
- **The label links them.** The base game's `dlc.pac` tables map each add-on label (the end of its content id) to a song id or costume number. All 117 song rows and all 63 costume rows match the user's add-ons.
- **Base game:** 8 of the 125 songs (0120, 0130, 0340, 0670, 1120, 1320, 1370, 1460) and every costume not in the costume table.
- **Costume numbers checked against `s_dress_datas` names:**
  - COS0001 → d031 "Bokura no LIVE Kimi to no LIFE"
  - COS0002 → d004 "Snow Halation"
  - COS0003 → d016 "Music S.T.A.R.T!!"

## 2. Port

- **`src/game/dlc/dlc.{h,cpp}`:**
  - `LoadCatalog` (label → song / costume);
  - `ScanOwned(folders)`, which reads labels from extracted add-ons (param.sfo `CONTENT_ID`) and `.pkg` headers, CUSA24620 only;
  - `Resolve` gives an `Ownership` (locked songs and costumes).
- **Setting:** `settings.ini` `[game] dlc_folder`. When it is empty, the port looks in the `Extracted` and `DLC` folders next to the dump.
- **Boot flow:** it logs `add-ons: N found; X of 117 add-on songs and Y of 63 add-on costumes locked`. The song select lists only owned songs and owned costumes.
  - Without the catalog, nothing is locked.
  - The developer flags (`--live`) are not filtered.
- **`tests/unit/dlc_test.cpp`** (`sif_dlc_test <dump> [add-on folder]`) checks:
  - the catalog (117 / 63, MUS0001 = 0010, MUS1049 = 1550, COS0001 = d031);
  - the scan of a fake extracted add-on, a fake `.pkg` and another title's add-on (ignored), written to a temp folder;
  - `Resolve` (owned, locked and base-game items).
- **Verified:**
  - all 12 tests pass, and Debug and Release are rebuilt;
  - the test finds 180 add-ons in both `Extracted` and `DLC`;
  - in the app (data folder `work/m7/dlc-run`), the detected folders give "0 locked, 125 songs", and an empty add-on folder gives "117 and 63 locked, 8 songs".

## 3. Not done

- **Locked items stay hidden.** The game shows locked songs with a store link; the port hides them.
- **Not checked against the add-ons:** `license.dat`. The port treats an installed add-on as owned, the same as the console does after install. It does not decrypt or check licences.
- **Bundles:** `dlc_set_data.bin` sets are not used.
- **Missions:** they still count all songs; they should probably skip locked ones.

## 4. "All songs selectable"

This was already true for the songs whose files are in the dump: `LoadSongList` lists every song with a `live/NNNN` folder. Ownership now decides which of them are listed. The roadmap item is ticked.

## 3. Incident: writes outside the project folder

shadPS4 uses `<current directory>/user` only if that folder already exists. Otherwise, on Windows, it uses `%APPDATA%\shadPS4`, which the user already had from earlier shadPS4 use. The run therefore wrote there (23:54:29–23:55:29):

| File | Change |
|---|---|
| `config.json`, `users.json`, `custom_trophy/Notice.txt` | rewritten at start |
| `home/1000/savedata/CUSA24620/sce_sdmemory/memory.dat`, `sce_sys/param.sfo` | **SIF save data rewritten by the game during boot** |
| `…/sce_sdmemory/sce_backup/*` | **shadPS4's save backup replaced** with the new state |
| `log/shad_log.txt` | overwritten with this run's log |
| `shader/dumps/*` | 259 files added (the user's config has shader dumping on) |

No copy of the previous files was made, so this cannot be undone. **Prevention:** from now on, run shadPS4 only from `work/shadps4-run` with `work/shadps4-run/user/` created first (a separate portable user folder), and never with the user's AppData folder.

- **Difficulties (confirms the `Scor` variant mapping):** the AC song select lists EASY (level 1), NORMAL (4), HARD (5), EXTREME (8) and CHALLENGE (12, locked at first) for "Susume→Tomorrow". So variants 00–04 = easy … challenge.

- The AC notice screenshot (`nav-14.png`) shows the real live screen: 9 round buttons in an arc around the singers, each marked with a PS4 button icon. That gives the lane-to-button mapping (to be read off a clearer frame).
- **Rendering issue in shadPS4:** character models draw as black silhouettes (member select, club room). Stage and UI look correct. This does not matter for timing, but it would matter for using shadPS4 as a visual reference in M5.
- Stability: no crash in about 9 minutes of menus.

## 4. Open: how to measure timing

Options, both on song 0340 (Susume→Tomorrow) since it is unlocked:

1. **Visual/audio offset:** capture shadPS4's window and audio while a song plays without input. Find when notes reach their buttons relative to the music, and compare with this port's model (a note reaches its button at chart time + lead-in). Needs screen capture at ≥60 fps plus audio loopback, i.e. a capture tool such as ffmpeg (not installed) or OBS.
2. **Judgement sweep:** press lane keys from a script at chart times plus a fixed offset, read the Perfect/Great/… counts on the result screen, and repeat for several offsets. The centre of the Perfect range gives the game's own timing origin. Needs the script synchronised to the song start (e.g. from shadPS4's audio) and the lane-to-key mapping.

A user decision is needed on the method and on installing a capture tool.

## 3. Rules still assumed (U5, need the eboot)

All live in `src/game/live/judge.cpp`, each marked *Hypothesis*:
1. Combo: Perfect and Great keep it, Good and Miss break it.
2. Score: weights 1.0 / 0.7 / 0.2 / 0 over 1,000,000 ÷ judgements. Placeholder: the real formula is in `s_CommonParam` floats and the eboot.
3. Holds: the release is judged with group 1; a missed press also misses the release; holding past the release window is a Miss.
4. Lane order: note 55 is the leftmost lane.
5. Note approach time: 1,300 ms for every difficulty (`s_CommonParam` probably has per-difficulty values).

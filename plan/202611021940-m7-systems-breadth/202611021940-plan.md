# M7: systems breadth, step 1: the port's own save

Created: 202611021940 (Asia/Jakarta). User decision: "Start M7 (save format)" (after `plan/202611011550-m6-ui-boot-flow/202611021938-plan.md`).

## 1. Goal of this step

A save that keeps the player's results, so the screens can show records:
- song select cards: rank, clear status;
- result screen: "NEW" marks and the old best;
- top menu header: name, counts.

It is the port's **own** format, not the PS4 save: the game's save is encrypted per console and not needed.

## 2. Design

- **File:** `save.txt` in the data folder (next to `settings.ini` and `sif.log`). It is plain text, so a user can read it and back it up.
- **Format** (one record per chart; unknown lines are kept, so a newer port's lines survive an older one):

  ```
  sif-port save 1
  player <name>
  record <song> <variant> <best score> <best combo> <best rank> <best rate x 10000> <plays> <clears> <full combos>
  ```

- **Safe write:** write `save.txt.tmp`, flush, then replace `save.txt`. A crash mid-write leaves the old save intact.
- **Update rule:** after a live that ends normally (not quit), `plays + 1`. Each best (score, combo, rank, rate) is kept if higher. `clears + 1` when the song was played to its end; `full combos + 1` when there was no Good, Bad or Miss. The update reports which bests are new, for the result screen's "NEW" marks.
  - *Hypothesis:* the game counts a clear by its life gauge; the port has no life gauge yet, so finishing counts.
- **Code:** `src/game/save/save.{h,cpp}` (game-specific, not engine), and a unit test `tests/unit/save_test.cpp` (round trip, update rule, kept unknown lines, safe-write leftovers).

## 3. Use in this step

1. The boot flow loads the save at start, updates it after each finished live, and writes it.
2. The result screen shows the "NEW" marks (`common_uip0017_New_0k` in `uil0005_PlayScoreWin00`, now always hidden) for new best score, combo and rate.
3. The song select's difficulty cards show the best rank (`lank_result00` / `clearrank00`, `setup_result_evaluation00`) once a chart has been played. The "Unplayed" plate texture stays for unplayed charts.

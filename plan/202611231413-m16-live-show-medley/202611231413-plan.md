# M16: Live Show Medley

Date: 2026-11-23 14:13 (Asia/Jakarta). Survey: `analysis/202611231413-live-show-medley/202611231413-analysis.md`.

**Goal:**
- Play → Live Show Medley opens the game's Set List screen.
- A recommended Set List, or one of your own, plays its songs one after another as View Live Show does, with the game's title between songs.
- You can make, edit, name and save your own Set Lists.
- The Medley missions count.

**Exit test:**
- **Recommended lists:** the current group's rows of `s_medley_datas` are listed, filtered by add-ons. One list plays through, song by song, with the title between songs.
- **Your own lists:** a list is made, named, saved, played and edited, and it is kept across restarts.
- **Missions:** kinds 14, 15, 37 and 47 count; a unit test covers each.
- **Capture:** a capture matches the game's Medley screens (shadPS4).
- **Checks:** all routes and unit tests pass, and the asset scan is clean.

## Steps

### R1: rules (eboot, no code)
- **The table:** the meaning of +0x2c and +0xd0.
- **The Set List screen:** the nodes of `uil0050_MedleyLayout00`, and the keys `medley_menu00-03`, `medley_music00`, `medley_costume00`, `medley_stage00`.
- **Between songs:** `uil0004_MedleyMode00`, `medley_title_T_<song>`, `ef_655` and `s_medleyIntervalCameraAnimParams`.
- **The end:** `result_medley00`, and the two choices "Watch the Same Medley List" / "Return to Medley Selection".
- **Other questions:**
  - how many lists of your own the game keeps;
  - the default name and the name entry;
  - what counts for kinds 14 and 15 (the time watched).
- **Output:** an analysis file. Anything not found becomes a stated *hypothesis*.

### R2: shadPS4 run (needs the user's approval; the user's build)
- Capture the Medley menu, a recommended list, the edit screen, one change of song, and the end of a medley.

### R3: data and save
- `medley::Data`, which loads `s_medley_datas`.
- Your own Set Lists in the save: a song, a costume and a stage per entry, and the name. Older saves read with no lists.
- The medley counters for the missions.
- **Tests:** the table, and the save round trip.

### R4: the medley live
- `live_screen` plays a list: song after song in View Live Show mode, with the title between songs, the medley HUD, and the end choices.
- **Route:** a short recommended list played through.

### R5: the Set List screens
- The Medley menu, the recommended lists, your own lists, and editing (song, costume, stage, name).
- **Route:** make, name, save and play a list.

### R6: missions and close
- Count kinds 14, 15, 37 and 47.
- Update PLAY.md and add a new CHECKLIST.md section.
- Run all routes and unit tests and the asset scan, and update the roadmap.

**Order:** R1 → R2 → R3 → R4 → R5 → R6. R1 and R2 can swap.

## Out of scope
- Others' Set Lists (online).

## Risks
- **The name entry:** the game uses the PS4 on-screen keyboard. *Fallback:* keep "Original Set List N", or type with the PC keyboard.
- **Loading between songs:** each song loads its own stage, members and music. *Fallback:* a short fade and a loading pause, as the live screen does today.

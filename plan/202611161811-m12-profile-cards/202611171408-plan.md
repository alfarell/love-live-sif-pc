## P6a: the card and the Profile Card menu
- **`DrawProfileCard`:** fills `uip0019` from a `save::ProfileCard` (or an edit in progress):
  - the photo (`profile_card.png` once saved, else the chosen photo), cropped by `crop`;
  - the frame, the accolade, badge and name plate;
  - the texts: song and costume (from the photo's live and member card), badge text, player name, member name, Friendship level (*shortcut:* 1, Friendship not built), skill name and level ×3;
  - portrait or landscape.
- **Collection → Profile Card** opens the menu (it opened Change Accolade straight away since M7):
  - the current card on the left (or the frame's empty placeholder);
  - the current accolade and nameplate;
  - Change Accolade or Name Plate (the M7 screen);
  - Create a New Profile Card, greyed without a photo (`profile::CanCreateCard`);
  - Everyone's Profile Cards, greyed (online);
  - the "Card-setting member" tag with the played member's icon.
- **Route:** `profile_menu` with a seed card and photo.

## P6b: Edit Profile Card
- **Opening:** Create (with "Create a new Profile Card?" when a card exists) opens the editor on the current card's values, or on defaults: the member's initial frame, portrait, the newest photo, the current nameplate choices, the member's set skill cards.
- **Tabs:** Card Frame (owned frames in portrait and landscape), Photo (the 4-column photo list; □ opens the position adjustment, left/right moves the crop), Accolade, Name Plate, Badge (the M7 lists), Skill Card (the member's owned cards, up to three), Finish Editing.
- **The preview** shows the card live.
- **Finish Editing:** saves the card (`profile_card` line) and copies the photo to `profile_card.png`.
  - *Shortcut:* no upload, and no "upload to the server" question (the game's upload fails offline anyway).
- **Route:** `profile_create` (after `live_view`'s photos): create, change the frame to landscape, choose a photo, save, and check the save line and the menu's card.

**Order:** P6a → P6b. Each is built, checked on Release and committed when the user asks.
